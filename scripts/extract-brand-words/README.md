# 店小秘 SHEIN 商品品牌词提取

> 当前状态：**待验收（只读/复制）**

## 功能

- 提取商品标题第一个疑似品牌词。
- 去重后复制到剪贴板。

## 使用与验收

- 打开店小秘 SHEIN 草稿、在线或下线商品列表。
- 点击“提取品牌”，检查剪贴板结果。

## 风险与限制

- 仅按大写字母等文本规则初筛。
- 不能替代商标数据库检索或侵权判断。
