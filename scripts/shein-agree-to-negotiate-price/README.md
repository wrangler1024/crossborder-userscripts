# SHEIN 批量议价

> 当前状态：**暂停分发·高风险**

## 功能

- 获取全部或指定 SKC 的待议价数据。
- 分批接受平台建议价。

## 使用与验收

- 仅使用测试店铺和明确的 SKC 白名单验收。
- 验收前导出待议价清单并人工复核。

## 风险与限制

- 同意建议价会直接改变商品报价。
- “拒绝并放弃上新”入口尚未开发。

## 安装

当前不向运营开放安装。开发或验收人员确认风险后，可使用以下 Raw 地址安装：
