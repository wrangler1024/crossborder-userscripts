# 安装与验收（开发版 v0.1.0）

## 安装（Chrome / Comet，加载已解压扩展）

1. 构建开发目录（仓库内执行）：

       sh extensions/xynigo-dxm-fulfillment-timing/build.sh --dev

   产物：`dist/xynigo-dxm-fulfillment-timing-dev/`

2. 打开浏览器扩展管理页（chrome://extensions），开启右上角「开发者模式」；
3. 点「加载已解压的扩展程序」，选择 `dist/xynigo-dxm-fulfillment-timing-dev/` 目录；
4. 打开店小秘「其他功能 → 物流追踪」，页面右下角出现深蓝"时"字悬浮球即注入成功。

发布 zip（`--release`）同样通过扩展管理页「加载已解压的扩展程序」选择解压后的目录安装，或直接将 zip 拖入扩展管理页。

## 使用

1. 在物流追踪页按需要筛选（如：已签收面板 + 时间范围 + 店铺账号）；
2. 点右下角悬浮球展开面板，点「开始统计」——插件按当前筛选范围自动翻页采集，期间可暂停/停止；
3. 面板内可继续用 店铺账号 / 订单 / 物流方式 / 目标国家 / 下单日期 / 发货日期 即时细分统计；
4. 「导出明细 CSV」导出筛选后全部订单；「导出当前汇总 CSV」导出当前维度表。

## 验收清单（真机）

- [ ] 开始统计后进度推进，全量采集单数与页面"已签收"总数一致（按同一筛选范围）；
- [ ] 任选 10 单，导出 CSV 中的下单/发货/上网/揽收/签收时间与页面"+展开"轨迹逐项一致；
- [ ] 揽收时效分段：J&T 单揽收=首条轨迹时刻；FedEx/iMile 单与轨迹 Pick-up / Received 时刻一致；
- [ ] FedEx 单出现负值揽收时效时，拆解表红色标注"含 N 单负值"；
- [ ] 店铺账号输入"蓝政"等关键词，命中多个店铺账号且统计联动；
- [ ] 订单框粘贴多个订单号/包裹号/运单号（空格或换行分隔）可批量命中；
- [ ] 口径切换（小时/自然日）、分段阈值修改即时重算，刷新页面后阈值与口径保留；
- [ ] 导出明细 CSV 用 Excel 打开不乱码，且不含收件人字段。

## 已知事项

- 首次"开始统计"前若页面从未加载过列表数据，插件会使用默认参数（已签收+全部店铺）采集；先在页面上应用筛选再点统计可获得与页面一致的精确范围；
- 物流追踪"可用条数"为承运商查询计费，本插件读取的是已存储数据，理论上不消耗；如发现消耗请立即停止使用并反馈；
- 店铺账号名显示为数字（shopId）时说明店铺名映射来源缺失，请反馈页面截图。
