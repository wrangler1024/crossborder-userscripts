# 安装与验收(v0.1.16)

本插件提供两种安装方式,**二选一即可**(同时启用不会出现双面板,但偏好互不同步):

## 方式一:Chrome / Comet 扩展(推荐团队统一分发)

1. 构建开发目录(仓库内执行):

       sh extensions/xynigo-dxm-fulfillment-timing/build.sh --dev

   产物:`dist/xynigo-dxm-fulfillment-timing-dev/`

2. 打开浏览器扩展管理页(chrome://extensions),开启右上角「开发者模式」;
3. 点「加载已解压的扩展程序」,选择 `dist/xynigo-dxm-fulfillment-timing-dev/` 目录;
4. 打开店小秘「其他功能 → 物流追踪」,页面右侧垂直中部出现白底圆角青边护盾按钮即注入成功。

正式发布包(推荐普通同事使用):从 [GitHub Releases](https://github.com/wrangler1024/crossborder-userscripts/releases) 下载 `xynigo-dxm-fulfillment-timing-v0.1.16.zip`,解压后按同样方式加载;或直接把 zip 拖入扩展管理页。后续升级:重新下载新版本 zip,在扩展管理页「重新加载」即可。

## 方式二:Tampermonkey 油猴脚本(免开发者模式)

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)(团队通用流程见仓库 `docs/how-to-install.md`);
2. 点击仓库 README 中本脚本的「一键安装」链接,或直接打开:

       https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/dxm-fulfillment-timing/xynigo_dxm_fulfillment_timing.user.js

3. Tampermonkey 弹出安装确认页,核对名称(Xynigo 店小秘履约时效助手)与版本后点「安装」;
4. 打开物流追踪页即生效。**自动更新**已配置(`@updateURL`/`@downloadURL` 指向仓库 raw 地址),Tampermonkey 会按其检查周期自动提示升级。

## 使用

1. 在物流追踪页按需要筛选(建议先切到「已签收」面板);
2. 点右侧护盾按钮展开面板,点「开始统计」——插件按当前筛选范围自动采集全部已签收订单;
3. 面板内六维筛选输入后点「筛选」生效;阈值可调并记住;口径可切小时/自然日;
4. 导出:明细 CSV / 当前维度汇总 CSV / 发货异常明细(仅异常单)。

## 验收清单(真机)

- [ ] 采集单数与页面"已签收"总数一致(同一筛选范围);进度推进可暂停/停止;
- [ ] 任选 10 单,导出 CSV 的下单/发货/上网/揽收/签收时间与页面"+展开"轨迹逐项一致;
- [ ] 上网时间缺失的单,CSV 标注「轨迹起始时间补取」;页顶上网状态行计数正确;
- [ ] 发货异常(上网早于下单)单:页顶红色告警计数、明细单号红标、导出明细三处一致;
- [ ] 揽收负值单:前端统计不含、无红色提示;明细 CSV 保留原始负值;
- [ ] 店铺账号输入"蓝政"等关键词命中多个店铺;订单框批量粘贴(空格/换行/逗号)命中;
- [ ] 筛选输入后不点「筛选」统计不变,点后生效;重置需再点「筛选」;
- [ ] 阈值输入非法(非正整数/非递增)出现错误提示且不应用;恢复默认可用;
- [ ] 口径切换即时重算;刷新页面后阈值与口径保留(扩展存储/GM 存储各自生效);
- [ ] 导出 CSV 用 Excel 打开不乱码,且不含收件人字段;
- [ ] 扩展与油猴同时启用时只有一个护盾按钮和一个面板。

## 已知事项

- 首次「开始统计」前若页面从未加载过列表数据,插件使用默认参数(已签收+全部店铺)采集;先在页面上应用筛选再点统计可获得与页面一致的精确范围;
- 物流追踪"可用条数"为承运商查询计费,本插件读取已存储数据,理论上不消耗;如发现消耗请立即停止使用并反馈;
- 店铺账号显示为数字(shopId)时说明店铺名映射缺失,请反馈页面截图。
