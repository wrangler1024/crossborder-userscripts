# 履约护盾 B1 草稿

用户选定B方向后的首轮可视稿，尚未确认定稿，不替换icons目录。

- 深蓝盾形 #0B315E：履约监控与数据可信度。
- 青色肩沿 #20AEB3：Xynigo家族识别。
- 白色钟针：时效；省略表盘刻度以保留16px可读性。
- 珊瑚红右侧切口 #FF694A：发货时序异常识别能力，不指揽收负值，也不表示当前已有报警。
- SVG为可编辑几何母稿，母版PNG为1024×1024 RGBA；16/32/48/128均为透明PNG。
- 评审图提供128px家族并排及16px浅色、深色背景比较；评审图背景不属于图标资产。

运行 `python3 render.py` 可重复生成草稿及评审图（依赖Pillow；评审文字默认使用macOS黑体）。

待验收：16px盾形/钟针是否足够清楚，红色切口比例，家族并排视觉重量。用户确认后再输出正式命名资产及icons/README.md。
