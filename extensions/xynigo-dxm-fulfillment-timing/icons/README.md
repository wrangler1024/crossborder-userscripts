## 视觉语义

- 深蓝盾形：全链路履约监控与数据可信度。
- 青色肩沿：Xynigo 家族识别，与采购助手、验证码助手保持同族配色。
- 白色钟针：时效统计；省略小刻度以保证小尺寸轮廓清晰。
- 珊瑚红切口：发现上网早于下单等发货时序异常的能力。不是当前报警状态，也不指揽收负值。

## 设计源与生成方式

可编辑 SVG、生成脚本及家族并排评审图位于 `../design/履约护盾草稿_20260915/`。
`render.py` 使用同一套几何定义输出 SVG 和 PNG，通过高分辨率绘制及 Lanczos 缩小生成各尺寸；依赖 Pillow，评审图字体默认使用 macOS 黑体。

本次只替换图标及补充设计说明，不修改 manifest 或功能代码。开发目录与安装包须在后续打包阶段重新构建才能包含新图标。push、tag、Release 仍暂停，等待用户明确恢复发布。
