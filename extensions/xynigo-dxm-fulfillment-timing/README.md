# Xynigo 店小秘履约时效助手

> 版本：0.1.16
> 状态：功能阶段验收通过。在店小秘「物流追踪-已签收」面板一键统计备货/揽收/尾程/运输/履约时效,监控"上网早于下单"的发货异常;全部计算在本地完成,只读不改任何平台数据。

## 背景与口径

店小秘物流追踪自带的"运输天数/运单天数"是物流侧口径(实测 FedEx 单显示"运单 2 天",实际下单→签收 139.8 小时),且没有任何界面提供"下单→签收"的履约时效统计。本插件计算店小秘没有的五个指标:

| 指标 | 定义 |
|---|---|
| 备货时效 | 发货时间 − 下单时间 |
| 揽收时效 | 物流揽收时间 − 发货时间(透视无轨迹头程的唯一窗口) |
| 尾程时效 | 签收时间 − 揽收时间(备货+揽收+尾程 恒等于履约) |
| 运输时效 | 签收时间 − 上网时间(上网=目的国轨迹起点,预上网) |
| 履约时效 | 签收时间 − 下单时间(全程主指标) |

- 主口径精确到小时,面板可切换"自然日"并列展示;全部时间为北京时间(店小秘官方确认)。
- SHEIN 全托管头程(中国仓→目的国)无轨迹,揽收时效是头程时长的唯一观测窗口。
- 揽收时刻从轨迹按承运商节点提取:FedEx=Picked up、J&T=Pick-up、iMile=Received。
- **揽收早于发货登记(揽收时效负值)属发货登记滞后,是正常现象**:不计异常、前端不展示(明细 CSV 留档原始值)。
- **发货异常(重大业务事故)= 上网时间早于下单时间**:页顶红色告警 + 独立导出,涉嫌虚假发货/运单复用,需重点排查。

## 数据来源(接口直读)

不依赖店小秘导出表格。插件复用页面自身接口 `POST /api/tracking/pageList.json` 分页拉取**当前面板筛选范围**的订单,并强制 `stateType=delivered` 只统计已签收:

- 单条记录含 orderCreateTime / shippedTime / onlineTime 毫秒时间戳(精确下单/发货/上网);
- lastEvent 文本尾部含签收时刻;originaInfo 内嵌完整轨迹 JSON,揽收节点零额外请求;
- 上网时间优先取接口值,缺失时取最早有效轨迹时间并在 CSV 标注"轨迹起始时间补取";
- 每页 1000 单限速翻页,带进度、暂停与停止;读取已存储数据,不触发新的承运商查询;
- 店铺账号名通过 index.json `accountMap.{平台}[].{id,name}` 映射,缺失时回退 shopId。

## 功能

- 右侧垂直中部护盾悬浮按钮(48px,白底圆角青色边框),点击/Enter 展开;面板展开时隐藏,收起后显示;
- 面板靠右、最大宽 920px、高度 80vh,四个维度页签固定在导出栏上方,首屏可见;
- KPI:统计单数、平均履约时效、中位数、P90、达标占比(全部问号悬浮定义);
- 分段占比:阈值默认 ≤5 / 6-7 / 8-9 / >9 天,面板可改(正整数且严格递增,错误输入不应用,支持恢复默认),阈值与口径偏好持久化;
- 时效拆解:五指标平均/中位/P90/最长 + 构成堆叠条(备货+揽收+尾程=履约)+ 行内比例图示;
- 发货异常:页顶红色告警条 + 明细单号红标 + 「导出发货异常(N)」(不受 10 单预览限制,无异常禁用);
- 维度统计:分店铺账号 / 分物流方式 / 分国家 / 按下单日,页签点击定位;
- 六维筛选:店铺账号(模糊,可命中多店)、订单(批量,空格/换行/逗号分隔,自动匹配订单号/包裹号/运单号,最多 1000 个)、物流方式、目标国家、下单日期区间、发货日期区间——**输入后需点「筛选」生效,重置同样需确认**;
- CSV 导出:明细(含上网时间来源/发货判定列,剔除收件人等隐私字段)、当前维度汇总、发货异常明细;BOM UTF-8,Excel 直开。

## 安全边界

- 全程只读:不写任何店小秘数据,不点击批量操作;
- 采集、解析、统计全部在本机浏览器完成,不经过任何第三方服务;
- 明细与 CSV 不含收件人姓名、电话、地址等隐私字段;
- 仅注入 `https://*.dianxiaomi.com/web/otherFeatures/tracking*` 页面。

## 已知限制

- 揽收节点白名单覆盖 FedEx / J&T / iMile;其他承运商走通用兜底,未命中时该单不参与揽收时效;
- 揽收时效统计剔除负值样本(发货登记滞后),`covered` 只计非负订单;
- 上网时间缺失时的"轨迹起始时间补取"是近似值,CSV 已注明来源;
- 扩展与油猴脚本同时启用时只会出现一个面板(双重防重),但偏好分别保存在扩展存储与 GM 存储,互不同步;
- 店小秘接口字段变更时解析需要升级。
