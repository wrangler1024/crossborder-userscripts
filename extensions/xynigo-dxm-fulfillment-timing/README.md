# Xynigo 店小秘履约时效助手（MVP）

> 版本：0.1.0
> 状态：接口直读架构首个开发版。在店小秘物流追踪-已签收面板一键统计备货/揽收/运输/履约时效，全部计算在本地完成，只读不改任何平台数据。

## 背景与口径

店小秘物流追踪自带的"运输天数/运单天数"是物流侧口径（实测 FedEx 单显示"运单 2 天"，实际下单→签收 139.8 小时），且没有任何界面提供"下单→签收"的履约时效统计。本插件计算店小秘没有的四个指标：

| 指标 | 定义 |
|---|---|
| 备货时效 | 发货时间 − 下单时间 |
| 揽收时效 | 物流揽收时间 − 发货时间（透视无轨迹头程的唯一窗口） |
| 运输时效 | 签收时间 − 上网时间（上网=目的国轨迹起点，预上网） |
| 履约时效 | 签收时间 − 下单时间（全程主指标） |

- 主口径精确到小时，面板可切换"自然日"并列展示；
- SHEIN 全托管头程（中国仓→目的国）无轨迹，揽收时效是头程时长的唯一观测窗口；
- 揽收时刻从轨迹按承运商节点提取：FedEx=Picked up、J&T=Pick-up、iMile=Received（已签收 Received 文本，勿混淆——J&T 签收文本含全角"Received！"）；
- 揽收时效可能为负（物流商实际接手早于发货登记时间），**保留负值并红色标出**，不按 0 截断；
- 下单/发货/轨迹时间店小秘官方确认为北京时间。

## 数据来源（接口直读）

不依赖店小秘导出表格。插件复用页面自身接口 `POST /api/tracking/pageList.json` 分页拉取**当前面板筛选范围**的已签收订单：

- 单条记录含 orderCreateTime / shippedTime / onlineTime 毫秒时间戳（精确下单/发货/上网）；
- lastEvent 文本尾部含签收时刻；
- originaInfo 字段内嵌完整轨迹 JSON，揽收节点零额外请求；
- 翻页限速 400ms/页，带进度、暂停与停止；读取的是已存储追踪数据，不触发新的承运商查询；
- 店铺账号名通过 index.json / authList 建立 shopId 映射，缺失时回退显示 shopId。

导出表格路径保留为设计上的降级备份，当前版本未启用。

## 功能

- 悬浮球 + 可拖动面板，只在物流追踪页注入，不影响页面本身操作；
- 开始统计：按当前面板筛选范围采集全部已签收订单；
- KPI：统计单数、平均履约时效、中位数、P90、达标占比（全部带问号悬浮定义）；
- 分段占比条：阈值默认 ≤5 / 6-7 / 8-10 / >10 天，可在面板调整并持久化；
- 时效拆解：四指标平均/中位/P90/最长 + 构成堆叠条（平均履约=三段之和）+ 行内比例图示；
- 维度统计：分店铺 / 分物流方式 / 分国家 / 按下单日；
- 六维筛选：店铺账号（文本模糊，可命中多个店铺账号）、订单（自动匹配订单号/包裹号/运单号，空格/换行/逗号分隔批量，最多 1000 个）、物流方式、目标国家、下单日期区间、发货日期区间——全部对已采集数据客户端即时生效；
- CSV 导出：明细 = 店小秘原生字段（剔除收件人等隐私字段）+ 履约/备货/揽收/运输时效、揽收时间、上网时间、签收时间、时效分段等扩展列；BOM UTF-8，Excel 直接打开。汇总 = 当前维度统计。

## 安全边界

- 全程只读：不写任何店小秘数据，不点击批量操作；
- 采集、解析、统计全部在本机浏览器完成，不经过任何第三方服务；
- 明细与 CSV 不含收件人姓名、电话、地址等隐私字段；
- 插件不保存订单数据，面板关闭后数据仅在当前页面存续；
- 仅注入 `https://*.dianxiaomi.com/web/otherFeatures/tracking*` 页面。

## 已知限制

- 揽收节点白名单覆盖 FedEx / J&T / iMile（当前主力渠道）；其他承运商走通用兜底规则，未命中时揽收时效为空并从该指标统计中剔除；
- 揽收时效负值是真实数据特征（发货登记滞后），非计算错误；
- 店铺账号名映射依赖 index.json/authList 返回结构，缺失时显示 shopId；
- 分页速率固定 400ms/页，全量 14867 单约 1-2 分钟；
- 店小秘接口字段变更时解析需要升级。
