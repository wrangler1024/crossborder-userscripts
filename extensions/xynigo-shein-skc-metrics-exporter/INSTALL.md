# Xynigo SHEIN 商品分析指标导出安装说明

版本：`0.2.0`

同一个 ZIP 可安装到 Google Chrome、Comet、HubStudio/Hub 浏览器以及其他支持 Manifest V3 的 Chromium 浏览器，不依赖 Tampermonkey。

> 这是一个只读工具：不发送任何写请求、不修改后台数据，采集方式等同于人工逐页查看并点击“下一页”。20260911 已在真实店铺卖家后台“数据-商品分析-商品明细-SKC列表”完成端到端验收（表格识别、商品首列拆分、自动翻页、CSV 导出）。

## 0.2.0 新增

- **导出 Excel（含商品图）**：数据行首列为“图片URL”，商品缩略图直接嵌入 A 列单元格（行高自动加高）；同图去重存储，个别图片转换失败自动降级为 URL 文本并在状态栏提示。
- **价格拆分**：原「价格」列（原价：x~y特价：a~b）拆为「原价」「特价」两列；区间两端相同合并为单值，可勾选关闭。
- **Excel 可计算**：GMV（自动去掉 MXN 前缀）、销量等写为数字；点击率/加车率/支付率/品质负向反馈率写为百分比格式（0.00%）；SKC/SPU/供方货号等保持文本防止精度问题；CSV 仍导出页面原始文本。
- 图片来自页面已加载的 CDN 资源（img.ltwebstatic.com，跨域读像素已实测可用），插件不新增任何网络权限。

## 安装

1. 完整解压 ZIP，不要直接从压缩包内部打开文件。
2. 在目标 HubStudio 浏览器环境中打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压得到的 `xynigo-shein-skc-metrics-exporter-v0.1.0` 文件夹；文件夹内应直接看到 `manifest.json`。
6. 登录 SHEIN 卖家后台，进入“数据 - 商品分析 - 商品明细 - SKC列表”，选好日期范围与指标页签（如商品指标、流量指标），等列表加载出来并刷新页面。
7. 页面右侧出现“导出商品指标”按钮即表示安装成功。

如果 Tampermonkey 中已启用同名旧脚本，请先停用，避免两个版本重复运行。

## 首次验收

1. 先用“仅当前页”采集一次，核对：面板表头预览与页面列一致、CSV 行数与页面“共 N 条”一致、数值与页面抽查一致。
2. 核对无误后再用“自动翻页采集全部”，从小数据量（如选一个较短的日期范围）开始。
3. 导出 CSV 用 Excel 打开，确认中文不乱码、可用筛选和汇总；末列“页码”用于核对采集过程。
4. 若提示“未检测到数据表格”或“翻页后内容未变化”，说明页面结构与当前识别规则不匹配，请暂停使用并反馈页面情况，不要反复重试。

## 使用说明

- 插件导出的是**当前页面已渲染**的表格：日期范围、站点、指标页签都先在 SHEIN 后台选好，一次采集对应一个页签；需要多个指标组时分别采集，在 Excel 里以 SKC 列做筛选或合并。
- “导出指标”即列选择，默认全选；至少勾选一列。
- 自动翻页模式下可调页间隔（默认 1500 毫秒）与最大页数（默认 50，上限 200）。中途可点“停止采集”，已采集部分仍可导出。
- 结果会剔除整行完全重复的数据并单独计数；若“预期总条数”与采集行数不一致，结果区会标注提醒，请先核对再使用数据。

## 已知限制

- 20260911 真机验收基于单一店铺（墨西哥站）的 SKC列表：分组表头（商品/商品基本信息/交易/流量/质量/操作）、表头表体分离渲染、soui 分页、商品复合单元格拆分均按实测结构适配；其他站点若结构不同，需按实测调整。
- 一次采集对应页面当前显示的一个指标页签；需要商品指标、流量指标等多组时分别采集，在 Excel 以 SKC 列合并。
- 商品复合单元格按文本解析拆分（名称/SKC/SPU/供方货号/品类/备货款/状态）；个别商品单元格格式特殊时对应子列为空，原始文本始终保留在“商品(原始)”列可人工核对。
- 翻页采集中若某行在相邻两页重复出现（后台排序不稳定所致），插件按整行去重并在结果区标注剔除数量；“页码”列可核对每行来源。
- 翻页控件识别支持 SHEIN 自研 soui 分页与常见“下一页”结构；遇到非标准翻页会按单页结束并在结果区标注，不会采错数据。
- 扩展只在 `sellerhub.shein.com` 运行，不申请任何额外权限；数据只写入本机下载的 CSV，不上传任何服务器。

## 更新

本地加载的扩展不会自动从 GitHub 更新。收到新版本 ZIP 后：

1. 解压并覆盖旧扩展目录，或解压到新的固定目录。
2. 回到 `chrome://extensions/`。
3. 在扩展卡片上点击“重新加载”。
4. 刷新 SHEIN 卖家后台页面。

不要删除浏览器当前加载的扩展目录，否则浏览器重启后扩展会失效。

## 开发联调

在仓库根目录执行：

```bash
npm run build:xynigo-skc-export:dev
```

首次加载时选择固定目录 `dist/xynigo-shein-skc-metrics-exporter-dev`。后续重新构建并在扩展管理页点击“重新加载”即可。

## 权限与安全边界

- 扩展没有申请剪贴板、浏览历史、标签页、Cookie、下载或跨域访问权限。
- 仅在 `sellerhub.shein.com` 运行；没有后台 service worker，不发任何网络请求。
- 只读取页面已渲染的表格内容，唯一模拟交互是点击“下一页”翻页。
- 采集结果只生成本地 CSV 下载，不向第三方上传任何数据。
