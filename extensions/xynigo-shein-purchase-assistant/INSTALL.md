# 安装与运行

## 1. 准备 Xynigo Sourcing 主执行器

前置条件：

- HubStudio 客户端和环境可正常打开。
- HubStudio“团队偏好 → 全局设置 → 本地访问”已开启。
- Xynigo Sourcing 已安装并运行。
- 飞书企业自建应用已开通电子表格只读权限。
- 自建应用已获得《采购执行协作表》的访问权。
- 主执行器已配置采购执行协作表坐标，并能从系统钥匙串 / DPAPI 读取团队企业应用凭证。

插件、HubStudio 和云端通道共用一个 Xynigo Sourcing 主执行器进程，不需要另开采购助手终端或独立 `8767` 服务。无需安装 `hubstudio-cli`，也不要要求采购员配置系统 PATH。

HubStudio Local API 是独立的可选增强能力：开启后主执行器可以定位、打开和关闭环境；未开启时仍可在已经打开的 SHEIN 页面读取并填写收件信息。

## 2. 在 HubStudio 加载扩展

1. 打开目标 HubStudio 环境。
2. 地址栏进入 chrome://extensions/。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 如从 Release 下载，完整解压 ZIP 后选择其中的 `xynigo-shein-purchase-assistant-v0.5.2` 目录；本地开发选择仓库 `dist/xynigo-shein-purchase-assistant-dev`。
6. 固定工具栏里的“Xynigo SHEIN 采购助手”图标。

## 3. 配置本次会话

1. 点击浏览器工具栏中的采购助手图标。
2. HubStudio 环境中的执行器地址保持 `http://xynigo.localhost:8766`。插件会将旧版 `127.0.0.1:8767` / `xynigo.localhost:8767` 配置自动迁移到主执行器。
3. 点击“保存并检测”，插件会自动获取本次会话信息。
4. 确认显示“localhost 执行器已连接 · 自动配对完成”。
5. 如同时显示“HubStudio 自动化已就绪”，可使用环境定位、打开和关闭；如显示“HubStudio 自动化暂不可用，不影响当前页面填写”，仍可继续地址填写。

## 4. 地址填写

1. 在 SHEIN 完成人工选品、规格与数量核对，进入结算地址页。
2. 插件默认保持收起；点击页面右侧“采购助手”悬浮入口后，输入销售订单号或包裹号搜索。
3. 选择当前任务，点击“一键填写收件信息”。
4. 等待八项字段全部显示完成。
5. 如出现红色错误，停止并按提示人工检查，不要继续提交。
6. 人工补充并核验 CURP/RFC。
7. 人工核对姓名、电话、邮编、州、市和地址。
8. 确认无误后由采购员自行点击 SHEIN 原生按钮。

## 5. 停止

完成后按现行 SOP 关闭 HubStudio 环境。Xynigo Sourcing 主执行器是共用进程，不要为关闭采购助手单独终止它。

## 故障排查

- “Xynigo 主执行器未运行”：启动 Xynigo Sourcing；如果终端已经显示本地执行器运行，再检查团队偏好中的“本地访问”。
- “团队偏好的‘本地访问’未开启”：开启 HubStudio“团队偏好 → 全局设置 → 本地访问”。这是网页访问 localhost 的开关，不是 HubStudio Local API 开关。
- “未检测到 HubStudio 客户端运行”：启动并登录 HubStudio 客户端。当前页面填写仍可继续。
- “HubStudio 已运行，但 Local API 未开启或端口不可达”：在 HubStudio 中开启 Local API，或由管理员核对主执行器保存的 Local API 端口。当前页面填写仍可继续。
- “HubStudio Local API 需要本机安全密钥 / 认证失败”：由管理员在 Xynigo 主执行器本机安全配置中写入或更新 Key；不要把 Key 发给插件、写入项目文件或粘贴到日志。
- “自动配对失败”：确认插件为 v0.3.6 或更高版本，并确认本地执行器版本一致。
- “邮编稳定回读不一致”：先确认旧版已取消分配；新版会处理邮编建议、DOM 重建和自动重试，仍失败时保留现场人工检查邮编与州/市是否一致。
- “飞书应用凭证校验失败”：在 Xynigo 系统设置中重新验证团队企业应用连接；不要把 App Secret 写入插件目录或日志。
- “飞书应用无表格读取权限”：检查应用是否开通 Sheets 只读 API 权限，以及协作表是否对该应用可访问。
- “协作表暂无可识别任务”：检查表内是否存在“系统订单键”，或销售订单号与包裹号。
- “同一任务存在多组收件信息”：必须先在协作表人工确认正确地址。
- “字段未找到”：SHEIN 页面可能尚未加载完成或页面结构已变化；不要继续自动化。
- “州/城市选项未匹配”：保留现场，人工选择并记录原始表格值用于后续映射。
