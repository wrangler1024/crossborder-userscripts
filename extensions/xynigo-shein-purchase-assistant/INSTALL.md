# 开发候选安装

0.10.0 为开发候选，尚未发布。填色和后台提交需先部署新版云端代码，再更新本机执行器至0.17.24，最后更新扩展并刷新订单页面；能力未声明时不开放新参数。

```sh
npm run build:xynigo-shein-purchase:dev
```

扩展管理页启用开发者模式，选择 `dist/xynigo-shein-purchase-assistant-dev`。不要与另一个采购助手版本同时分配到同一环境。

「采购详情」需要执行器能力 `purchaseDetailsV1`。旧执行器仍可使用其支持的地址填写功能。截图由执行器通过 HubStudio 获取，插件无需屏幕录制授权。团队协作表及采购员分配必须先配置正确。

未经真实写入小批量验收和独立评审，不覆盖团队扩展或运营跟随的下载入口。
