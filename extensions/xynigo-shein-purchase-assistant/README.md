# Xynigo SHEIN 采购助手

版本：0.9.1 测试候选。新增动态等待提示及耗时；截图边界修复需配套执行器0.17.23。

## 功能

- 保留美国站、墨西哥站的任务搜索、地址填写、CURP、桌面托管数据源和快捷键。
- 新增「收件信息 / 采购详情」页签；在墨西哥站订单详情页选择任务，输入当前 HubStudio 环境序号，读取订单并截取单张长图。
- 订单号、已付款金额和币种来自当前订单结构化数据，并与页面 Total 核对。金额不以商品原价或优惠金额替代。
- 回传前预览截图并确认任务。只写采购订单号、实际付款、下单截图；不更新采购状态，不点击任何平台订单操作按钮。
- 同一任务多商品行的订单号写入各行，实际付款与截图只记录在当前第一商品行。手动拆单的完整订单号后缀参与任务身份。
- 同一次提交不能重复执行。不同内容需重新读取、填写修订原因；旧记录和截图保留。图片明确被拒绝时仅补传图片；网络结果未知时仅查询结果。

## 使用前提

需要配套实现 `purchaseDetailsV1` 的 Xynigo 桌面执行器、云端采购凭证服务，以及数据库迁移 `0035_purchase_receipts`。仅更新插件无法启用完整功能。按接收方先兼容、执行器和插件随后发布的顺序升级。

任务必须来自云端登记且已同步到桌面客户端的团队执行协作表。个人速填表不支持写入。普通采购员只可回传采购员列与本人账号 ID 或姓名精确匹配的任务；管理员按组织权限操作。

SHEIN 环境必须已打开。执行器通过随机页面标记核对指定环境和当前标签页，读取、截图及提交前均验证订单身份。任务标识在扩展会话存储中按标签页保留 30 分钟，重新进入页面时仍须从执行器查询验证；姓名、电话、地址和截图不写入扩展持久存储。

## 初次使用

1. 打开当前订单详情页，展开采购助手，搜索并选择具体采购任务。
2. 切换「采购详情」，输入本次环境序号，点击「读取订单并截图」。
3. 核对订单号、金额、目标表与截图，勾选确认后回传。
4. 如提示结果未知，点击「查询回传结果」，不要另建提交。明确截图失败时点击「仅补传截图」。
5. 已完成订单需要修订时，点击「修订 / 重新下单」，重新读取并填写原因。此操作保留原凭证。

## 已知边界

- 采购详情仅覆盖已验证的墨西哥站桌面详情结构。美国站保留地址功能；其采购凭证尚未开放。
- 截图是读取时的订单详情凭证，并非历史付款瞬间截图或银行扣款回单。
- 最长截图限制 12,000 CSS 像素，JPEG 最大 3 MB；超限时停止，不静默截断凭证。
- 云端按任务锁定提交，但飞书普通表格并非事务数据库。操作期间应避免人工排序、插入和修改目标任务。写入前后复核，无法确认时停止并标记结果未知。
- 目前没有自动清除 unknown/pending 的管理入口；管理员须核对实际表格和持久提交记录，再安排恢复，不能盲目重复写入。
- 修改未由插件登记的人工记录会被阻止，避免覆盖未知来源凭证。
- 真实平台写入、Windows/HubStudio 安装及共享环境迁移仍需专项验收。开发包不是已发布版本。

## 开发与打包

在仓库根目录执行：

```sh
npm ci
npm run test:xynigo-shein-purchase
npm run build:xynigo-shein-purchase:dev
```

扩展权威源在本目录，`build.sh` 生成开发目录及 ZIP。生产权限仍仅 `storage`；没有添加全站截图、debugger 或支付权限。截图由用户本机执行器完成。

0.9.0 吸收既有 0.8.2 测试快照中的地址与桌面数据源实现；迁移范围限于扩展 src、popup、manifest 及对应 JavaScript 回归测试。未移入旧独立执行器或配置文件。该迁移不表示历史测试快照已正式发布。
