# SHEIN 店铺接码助手安装与使用

> 版本：`0.1.1`
> 适用环境：HubStudio 中的 SHEIN 全球商家中心店铺环境

## Tampermonkey 一键安装

1. 浏览器先安装 Tampermonkey。
2. 打开[一键安装链接](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/shein-store-otp-assistant/xynigo_shein_store_otp_assistant.user.js)。
3. 在 Tampermonkey 安装页面确认脚本名称和版本，点击“安装”。
4. 打开 SHEIN 全球商家中心，点击 Tampermonkey 图标。
5. 在脚本菜单中点击“配置 SHEIN 接码链接”，粘贴当前店铺链接。
6. 点击“测试 SHEIN 接码链接”确认配置可用。

Tampermonkey 版与 HubStudio 团队扩展版只能选择一种启用，避免两个版本同时轮询和填码。

## 团队扩展安装

1. 打开需要配置的 HubStudio 店铺环境。
2. 点击浏览器右上角的“扩展”图标，进入“扩展管理”。
3. 选择“团队扩展”。
4. 找到“SHEIN 店铺接码助手”，点击“添加到环境”。
5. 刷新已打开的 SHEIN 页面；若仍无插件提示，关闭并重新打开该 HubStudio 环境。

## 当前店铺配置

1. 从 HubStudio 环境备注中复制当前店铺的完整接码链接。
2. 点击工具栏中的“SHEIN 店铺接码助手”图标。
3. 将链接粘贴到“接码链接”输入框并点击“保存配置”。
4. 点击“测试链接”。显示“链接可访问”即表示配置成功；当前没有新验证码时，“尚未检测到验证码”属于正常。

团队扩展只负责把插件安装到环境。每个 HubStudio 店铺环境使用独立的浏览器数据目录，必须分别配置一次对应接码链接。

## 日常登录

1. 输入 SHEIN 店铺账号和密码，手动点击“登录”。
2. 手机号码验证窗口出现后：
   - 页面已显示“已发送验证码，请查看”或秒数倒计时：无需再次点击“获取验证码”，插件会自动开始接码。
   - 页面仍显示“获取验证码”：由运营人员手动点击后，插件开始接码。
3. 等待插件收取并自动填入短信验证码。
4. 确认页面提示“已自动填入 6 位验证码”，再由运营人员手动点击“确认”。

插件不会自动点击“登录”“获取验证码”或“确认”。SHEIN 首次自动发码时，插件仅自动开始接码和填码。

## 本地开发包安装

1. 在仓库根目录运行 `npm run build:xynigo-shein-otp:dev`。
2. 打开 HubStudio 环境浏览器的 `chrome://extensions/`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择 `dist/xynigo-shein-store-otp-assistant-dev`。
5. 返回 SHEIN 商家中心页面并刷新一次。

## 异常处理

- **页面没有插件提示**：确认扩展已添加到当前环境，然后刷新页面或重新打开 HubStudio 环境。
- **一直等待新短信**：核对验证窗口的手机尾号与当前环境配置的接码链接，倒计时结束后可重新发送。
- **测试链接提示 HTTP 403**：在当前 HubStudio 环境的普通标签页中手动打开一次接码链接，再回到插件重新测试。
- **验证码没有自动填入**：确认验证窗口仍打开且页面右上角有插件运行状态，必要时关闭验证窗口后重新登录。

## 安全要求

- 接码链接包含私密 key，只能保存于对应店铺环境的扩展配置中。
- 禁止将接码链接、验证码或插件配置截图发送到群聊或无关人员。
- 仓库源码、构建包和测试样例不得包含真实接码链接、验证码或账号信息。
