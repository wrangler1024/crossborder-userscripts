# Xynigo SHEIN 采购售价对比

版本：0.1.4。支持 HubStudio / Chromium 的墨西哥站与美国站。

安装包与版本记录：[GitHub v0.1.4](https://github.com/wrangler1024/crossborder-userscripts/releases/tag/shein-price-compare-v0.1.4)。源码结构、链接协议与维护流程见 [开发说明](https://github.com/wrangler1024/crossborder-userscripts/tree/main/extensions/xynigo-shein-price-compare)。

## 安装或更新

1. 解压 `xynigo-shein-price-compare-v0.1.4.zip`，保留整个文件夹。
2. 在 HubStudio 环境浏览器打开 `chrome://extensions/`，开启开发者模式，选择“加载已解压的扩展程序”，加载内含 `manifest.json` 的目录。
3. 从旧版更新时，可用新文件替换原加载目录内容并点击“重新加载”；若改用新目录安装，请停用旧版，避免同时运行。更新后刷新商品页。
4. HubStudio 团队扩展上传使用 `xynigo-shein-price-compare-v0.1.4-hubstudio.zip`，该包根目录直接包含 `manifest.json`。插件名称填写“Xynigo SHEIN 采购售价对比”，扩展图标使用安装资料中的 240×240 PNG，再分配到需要的采购环境。

运营端继续使用商品型号助手 v0.1.22，无需同步升级。不依赖 Xynigo 执行器或飞书登录。

## 默认减少干扰（沿用 v0.1.2）

- **标准采购链接自动启用**：链接包含有效的商品编号、SKU、`xv=1`、`op` 与 `c`。默认只显示约 232px 宽、40px 高的小状态条。售价未变或下降时保持收起，可点击“详情”查看。
- **普通或无效链接默认不检查**：只显示“未启用”的小入口，不扫描商品、售价、库存或可售文案，也不创建页面内容 MutationObserver。点击“启用”后才检查可售状态；粘贴标准采购链接后可比价。
- **异常展开一次**：新检测到涨价、下架、不可售或型号售罄时自动展开。手动收起后，相同的异常不会在每次检查时重新弹出；涨价金额变化或出现另一种不可售状态时再提示。
- **稳定后降低频率**：初次载入和价格变化时，按约 500ms 采样，价格连续稳定至少 2.2 秒后停止高频检查。加载未成功时，高频重试约 15 秒后也转为低频。稳定状态每 30 秒兜底复核一次。
- **只响应相关变化**：记住价格、规格、购买控件与商品数据节点。相关内容变化时合并触发检查；推荐区、评论、插件自身更新以及无关计数变化不触发全页复核。
- **后台暂停**：标签页切到后台后停止完整扫描并断开内容监听，回到前台后重新检查。
- **可手动暂停**：展开后点击“暂停本页检查”；点击“启用”可恢复。手动暂停保持到再次启用或导航到一条新的有效标准链接。

普通页面仍保留每秒一次的 URL 字符串比较，以识别网页内部 SPA 跳转；该过程不读取页面商品数据。完整检查次数降低不等于在所有真实页面上已证明零性能影响。

## 价格与型号

使用运营型号助手的“复制采购链接”，而非三行备注中的普通链接。`op` 为审单时优惠券前的页面售价，不是划线原价；`c` 为 MXN 或 USD。可选 `pt` 是售价快照的 Unix 秒数，旧链接无此字段仍能比价，显示“采价时间未记录”。时间按采购电脑时区显示。

插件尝试定位链接唯一对应的型号，确认商品、SKU、商城与币种一致后比较实时页面售价。采购员手动切换型号后提示不一致，不会反复抢回原型号；可通过“定位链接型号”手动恢复。

普通链接手动启用后没有审单售价，不能计算差额。可展开“换用原采购链接 / 补充链接”，粘贴完整原链接。基准只保存于当前标签页内存；跨完整跳转丢失元数据时需要补贴原链接。

## 可售状态

- **商品已下架 / 商品不可售**：已启用的页面出现明确的英、西或中文商品状态提示，即使商品 JSON 或售价没有返回也可提示。
- **指定型号已售罄**：链接目标 SKU 库存为零、结构化数据标记售罄，或当前型号购买按钮显示售罄。
- **暂不可购买**：加购按钮禁用，不等于商品已下架。
- **页面可加购**：仅说明当前型号的可见加购按钮可用，实际库存以加购结果为准。
- **可售状态待确认**：数据不足、页面验证、未定位型号或未确认加购按钮。不会把缺价或加载失败判为下架。

不可售状态优先于价格结果。恢复后自动重新比价。提示采用有限的明确文案和控件规则，未覆盖的布局保持待确认。

## 边界与验证

不自动加购、下单、支付或写入飞书；不读取账号凭证。比较的是页面售价，实付以购物车为准。普通链接默认关闭后，也不会自动弹出不可售提醒，需要先手动启用。

已完成 37 项自动化测试，覆盖价格与可售状态回归、普通页零扫描、稳定页每分钟两次检查、后台暂停、相关变更触发、异常不重复弹出、SPA 切换、详情开关、拖动与等待进度。真实 HubStudio 多标签页性能尚未实测，页面较复杂时每次完整检查仍有成本；未被监听规则覆盖的变化由 30 秒兜底检查发现。

## 开发

执行 `npm run build:xynigo-price-compare:dev` 生成固定目录 `dist/xynigo-shein-price-compare-dev`。首次在扩展管理页点击“加载已解压的扩展程序”，选择该目录；后续修改后重复构建，再点击扩展卡片上的“重新加载”并刷新商品页。开发模式不生成 ZIP，不改动已发布的安装包。

仓库根目录执行 `npm run test:xynigo-price-compare` 与 `npm run build:xynigo-price-compare`。

构建时复用商品型号助手源码生成 `variant-library.js` 并禁用其界面启动；`watcher.js` 负责变化筛选，`content.js` 负责启停、采样调度和状态展示。采购端 v0.1.4 未修改运营端格式或解析源码。

## v0.1.3 家族图标

使用 Xynigo 海军蓝圆角底、小犀青价签、包裹黄孔环和珊瑚红上下箭头，表达“商品售价与涨跌”。扩展管理页、浏览器工具栏、页面状态条和展开面板使用同一图标。提供 16 / 32 / 48 / 128 px 运行尺寸；页面图标以打包内嵌 PNG 加载，不新增网络请求或站点资源权限。

此版本只更新品牌图标，沿用 v0.1.2 的普通链接默认关闭、异常展开和降低扫描频率规则。

## v0.1.4 详情窗口交互与等待进度

- 点击状态条图标、状态文字或空白区域都可打开详情，等待售价稳定时也能打开。普通链接点击后手动启用检查，右侧“收起”按钮仍可收起窗口。
- 点击插件窗口外的页面区域会收起详情，不阻止网页原本的点击动作，也不停止已启用的检查。插件内部按钮、输入框和自动定位型号不会被当成外部点击。
- 等待时状态条显示旋转指示，详情中显示动态进度条；进度来自实际采样的连续稳定时间。价格变化会重新计时，完成后自动停止动画。动画使用 CSS，不增加扫描计时器；遵循系统“减少动态效果”设置。
- 标题栏仍支持拖动，超过 5px 视为拖动，松手不误打开详情。文字入口支持 Enter / 空格键。
- 浏览器工具栏中的扩展图标也能打开当前 SHEIN 商品页详情，使用现有内容脚本消息通信，无新增站点权限。安装或重载扩展后，请先刷新已打开的商品页。

固定本地开发目录仍为 `dist/xynigo-shein-price-compare-dev`，构建命令不变。
