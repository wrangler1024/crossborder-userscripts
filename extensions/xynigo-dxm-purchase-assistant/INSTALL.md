# Xynigo 店小秘运营采购助手安装说明

协同测试版：`0.11.0-xynigo-test`；已发布公开预览版：`0.1.45`。

`0.11.0` 必须与同版本、包含“运营采购助手连接”的 Xynigo 测试客户端配合使用。它不再连接旧的 `8766` 草稿服务，也不再要求用户粘贴内部 Token。

## 加载本地联调版

1. 在扩展目录执行 `sh build.sh --dev`，生成 `dist/xynigo-dxm-purchase-assistant-dev`。
2. 在浏览器地址栏打开 `chrome://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择 `dist/xynigo-dxm-purchase-assistant-dev`，确认版本号为 `0.11.0`。
5. 扩展版和油猴版二选一，不要同时启用。

## 首次配对

1. 启动新版 Xynigo 本地服务；不要停止仍在使用的旧实例。
2. 在 Xynigo 内完成飞书登录，并确认当前账号拥有 `procurement.request.save` 和/或 `procurement.request.submit`。
3. 打开扩展弹窗，点击“连接 Xynigo”。
4. 浏览器会打开 `http://127.0.0.1:<Xynigo端口>/extension-connect`；核对插件标识后点击“确认连接”。
5. 重新打开扩展弹窗，确认显示的成员、组织与提单权限。

Xynigo 重启后本机桥接令牌会失效，按上述步骤重新连接即可。

## 合成验收

1. 使用经授权的测试订单打开“采购明细”。
2. 确认商品、图片、销售数量、币种、`US/MX` 站点和店小秘下单时间识别正确。
3. 点击“保存采购单”，界面应显示“云端草稿已保存”，编辑页保持打开。
4. 补齐每条明细的精确链接、指导价和数量，点击“提交采购单”。
5. 成功后应显示“已正式提交”；同一内容重试不生成重复采购单。
6. 全程不应填写店小秘备注，也不应改变审核按钮的样式、可用性或点击行为。

`syncStatus=pending` 是正常的云端队列状态，不可据此声称飞书 Base 已同步。真实 Base 写入必须等待同步 Worker 部署、字段预检通过和用户明确授权。

## 常见问题

- “未找到支持插件连接的 Xynigo”：确认新版 Xynigo 已启动在 `127.0.0.1:8765-8779` 之一。
- “请重新连接 Xynigo”：Xynigo 可能已重启或扩展已重载，重新配对。
- “已登录，但缺少提单权限”：请管理员在 Xynigo 角色策略中分配对应采购权限。
- “采购单已正式提交，不能直接覆盖”：当前版本不提供退回重提，不要通过重复保存绕过锁定。
- 页面提示扩展上下文已失效：重新加载扩展后强制刷新店小秘页面。
