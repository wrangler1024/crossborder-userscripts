# 安装与使用

版本：`0.1.4`

完整操作步骤见[操作文档](./OPERATIONS.md)；技术实现、接口边界和发布流程见[开发文档](./DEVELOPMENT.md)。

## 安装

### Chrome / Edge / Ego 原生扩展

1. 将 `lingxing-vine-promotion-assistant` 文件夹放到固定位置，安装后不要移动或删除。
2. 打开 Chrome / Edge / Ego 的扩展管理页，开启“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择包含 `manifest.json` 的本目录。
4. 刷新已打开的领星 ERP 页面。
5. 打开「销售 → 平台订单 → 订单列表」，页面右侧会出现“Vine 推广标注”入口；也可从浏览器扩展菜单打开。

入口按钮默认收为图标；鼠标悬停或键盘聚焦时展开待标摘要。按住按钮上下拖动可调整位置，位置会自动保存；点击按钮打开插件窗口。

### Tampermonkey 油猴版

1. 安装并在浏览器中启用 Tampermonkey。
2. 打开[油猴一键安装链接](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/lingxing-vine-promotion-assistant/lingxing-vine-promotion-assistant.user.js)，确认安装“领星 Vine 推广标注助手”。
3. 刷新已打开的领星 ERP 页面。
4. 打开「销售 → 平台订单 → 订单列表」，从页面右侧“Vine 推广标注”入口操作。

扩展与油猴版选择一种启用。油猴版按脚本更新地址自动检查新版本；历史检查摘要保存在当前领星站点的脚本本地存储中，不保存令牌、Cookie 或请求头。

更新时覆盖原目录，在扩展管理页点击重新加载，再刷新领星页面。

## 第一次只读验收

1. 在订单列表确认检查范围为近 30 天。
2. 点击“立即检查”，或等待每天首次自动检查。
3. 核对市场、店铺、订单号、SKU、ASIN、订单状态和金额。
4. 点击“导出预览”保存本批待标清单。
5. 先不要点击最终确认；将待标清单与领星原生订单列表人工对照。

只读检查不会调用写接口。

## 人工确认后标注

1. 勾选需要处理的待标订单。
2. 点击“确认标注 N 笔”。
3. 插件会再次只读复核所选订单；如订单已变化，会刷新列表并停止。
4. 在确认弹窗中勾选“已核对本批订单号、店铺和固定口径”。
5. 点击“确认标注”。
6. 等待逐小批提交和回读完成。
7. 查看每个订单的“核验通过 / 仍待标 / 结果待核实 / 未提交”状态，并导出执行记录。

推广类型保持默认。插件不会填写推广费用，不修改备注、退款或订单状态。

## 异常处理

- **等待领星会话**：刷新领星订单列表；扩展需要观察页面自身的一次正常请求。
- **订单状态已变化**：按刷新后的列表重新选择。
- **提交结果待核实**：先点击“回读上次批次”，不要重复提交。
- **回读未通过**：在领星原生订单列表核对 `isAssessed`，保留执行记录后人工处理。
- **限流、超时或权限失败**：插件停止，不自动重试写请求。

## 安全边界

- 页面通信层在把订单传给插件界面前剔除买家姓名、邮箱和地址；界面和本地记录不保存这些字段。
- 不保存 `auth-token`、Cookie、请求头或密码。
- 写接口固定为 `POST /amz-order/api/order/setAssess`。
- 每批最多 20 笔，必须经过插件的预复核和二次确认。
- 关闭或停用扩展不会撤销已经提交到领星的推广标记；如需撤销，应在领星原生界面人工操作。
