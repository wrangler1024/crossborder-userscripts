# 领星 Vine 推广标注助手 操作文档

适用版本：`0.1.4`。更新日期：2026-11-16。面向负责领星 Vine 订单推广标记的运营人员。

2026-11-16 运营测试确认本插件可用、已验收。

# 用它完成什么

在领星 ERP「销售 → 平台订单 → 订单列表 → 销售订单」中，助手会找出已有 Vine 标识、但还没有进入推广订单的销售订单。运营核对后，可把这些订单批量标记为推广订单，并查看每笔订单的回读结果。

助手遵循以下固定口径：

- 只看商品行是否含 `vine.enrollment.*` 标识。
- 只把 `isAssessed = 1` 视为已标；不根据 `isPromotion`、金额或买家信息猜测。
- `Pending`、已取消和退款状态的 Vine 订单仍纳入检查。
- 推广类型保持默认，不填写推广费用。
- 只执行“标记推广”，不修改订单状态、备注、退款、费用或其他字段。

助手不是后台自动标注工具。每天首次进入领星后的自动检查是只读的，不会自行提交；真正标注必须由运营选择订单、点击确认并完成二次核对。

# 安装和升级

## 油猴版

1. 在用于领星的浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开[领星 Vine 推广标注助手油猴一键安装链接](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/lingxing-vine-promotion-assistant/lingxing-vine-promotion-assistant.user.js)。
3. 在 Tampermonkey 的安装页确认脚本名为“领星 Vine 推广标注助手”，选择安装；已有同一脚本时选择更新。
4. 刷新已打开的领星 ERP 页面。
5. 打开订单列表，在插件窗口右上角核对“正式版 0.1.4”。

油猴版会按脚本的更新地址检查新版本。是否自动安装取决于 Tampermonkey 的更新设置和 GitHub 网络访问情况。需要立即更新时，可在 Tampermonkey 管理面板对该脚本执行“检查更新”，完成后刷新领星页面。

## Chrome / Edge 原生扩展

从 [GitHub Release](https://github.com/wrangler1024/crossborder-userscripts/releases/tag/lingxing-vine-promotion-assistant-v0.1.4) 下载扩展 ZIP 并解压。打开 Chrome / Edge 的扩展管理页，开启“开发者模式”，点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的文件夹**，不要选择 ZIP 文件本身。

原生扩展更新时需要覆盖原加载目录，在扩展管理页点击“重新加载”，再刷新领星页面。浏览器扩展没有商店自动更新。

油猴版和原生扩展版只启用一个。两者同时启用会出现重复入口，也不利于判断当前实际运行版本。

# 第一次只读检查

1. 登录正确的领星公司账号，进入「销售 → 平台订单 → 订单列表」。
2. 在页面右侧找到“Vine 推广标注”入口。入口默认收为图标，悬停会展开待标摘要；按住入口上下拖动可调整位置，位置会保存在本机。也可用键盘聚焦入口后按上下方向键移动，点击入口打开插件窗口。
3. 检查范围默认是“近 30 天”，也可选择近 7 天或近 90 天。切换范围会立即重新检查。
4. 若顶部显示“等待领星会话”，先刷新当前订单列表，再点击“立即检查”。
5. 等待页面依次完成读取订单、比对推广标记和生成待标预览。
6. 查看结果数字：
   - **销售订单**：所选日期范围内的订单总数。
   - **已进入推广订单**：Vine 订单中 `isAssessed = 1` 的数量。
   - **本次待标注**：Vine 订单中尚未标记的数量。
   - **Vine**：本次识别到的全部 Vine 订单数量。
7. 点击“导出预览”可保存当前勾选清单供复核。该文件只是 CSV 预览，不会提交标注。

检查会读取所选日期范围内的全部销售订单页，不是只读取当前屏幕或当前筛选结果。若范围过大、超过插件安全上限，应缩小到近 7 天或近 30 天后再查。

每日首次打开领星并取得会话后，助手会自动做一次只读检查；在订单列表发现待标订单时会打开插件窗口。若当天已有检查摘要，会先显示本机缓存；需要最新结果时点击“立即检查”或“重新检查”。

# 阅读待标清单

结果区只展示尚未标注的 Vine 订单。左侧市场分面显示各市场的待标数量；搜索框可按订单号、店铺、SKU、ASIN、市场和状态查找。

逐笔核对以下字段：

- 订单号、市场和店铺
- 下单时间
- 订单状态，包括 `Pending`、取消或退款
- 金额
- SKU、ASIN
- 识别结果是“Vine 待标”

默认会勾选全部待标订单。执行前请取消本批不处理的订单；点击“选择全部待标”可恢复全选，点击“清空”则取消所有勾选。

导出预览时只导出当前勾选订单。若需要完整清单，请先选择全部待标再导出。

# 确认标注

1. 再次核对已勾选订单的订单号、店铺和状态。
2. 点击底部“确认标注 N 笔”。
3. 助手会重新只读读取所选日期范围，确认这些订单仍然存在、仍为 Vine、仍待标。若某笔订单已变化，插件会刷新列表并停止本次提交。
4. 在确认弹窗中核对订单范围、默认推广类型和固定口径，勾选“已核对本批订单号、店铺和固定口径”。
5. 点击“确认标注”。
6. 等待小批提交和回读完成。选中超过 20 笔时会自动拆成多个小批串行处理；不要在提交过程中切换账号、刷新或关闭页面。

推广类型使用默认值。插件不会填写推广费用，也不会修改备注、退款或订单状态。

# 查看回读结果

提交完成后，结果页会逐笔显示：

| 状态 | 含义 | 处理建议 |
|-|-|-|
| 核验通过 | 回读确认该订单 `isAssessed = 1` | 无需重复处理，可按需导出记录 |
| 仍待标 | 领星已受理，但回读仍不是已标 | 在领星原生订单列表核对后再决定是否重新检查 |
| 回读未找到 | 当前检查范围或 Vine 集合中未找到该订单 | 保留记录，检查订单范围或联系维护人员 |
| 未回读 | 已受理，但回读请求失败 | 先查看“检查记录”和领星结果，再人工核对 |
| 结果待核实 | 写请求结果不明确 | 不要直接重复提交；先按提示回读 |
| 未提交 | 前序批次异常后，本批没有发送 | 查看前序错误，核对后再重新检查 |

如果顶部出现“上次提交结果尚未确认，请先回读”，必须先点击“回读上次批次”。该按钮只重新读取 `isAssessed`，不会重复发送标注请求。

如果结果不是全部“核验通过”，插件会停止后续提交，不会自动重复同一批。请保留结果页或导出执行记录，在领星原生订单列表核对后再人工处理。关闭、停用插件或删除本地记录不会撤销已提交的推广标记。

# 检查记录与导出

插件右上角“检查记录”中可查看最近 20 条只读检查和执行摘要。执行摘要显示标注笔数、受理笔数和回读通过笔数。

两类 CSV：

| 导出入口 | 内容 |
|-|-|
| 导出预览 | 当前勾选的待标订单，供提交前人工核对 |
| 导出本次记录 | 最近一次执行批次的市场、店铺、订单号、提交结果、回读结果和推广类型 |

导出的 CSV 带 UTF-8 BOM，可直接用 Excel 打开。下载 CSV 本身不会修改领星订单。

本地记录只保存在当前浏览器。清理领星站点数据或浏览器数据可能删除检查摘要、执行记录和入口位置；更换浏览器、设备或账号后不会自动同步。

# 异常处理

| 提示或现象 | 处理方式 |
|-|-|
| 一直显示“等待领星会话” | 刷新当前订单列表，确认领星页面正常加载；安装或更新脚本后也必须刷新页面 |
| 页面右侧没有入口 | 确认当前地址是「销售 → 平台订单 → 订单列表」；确认只启用一个渠道；刷新页面 |
| 窗口版本不是 0.1.4 | 检查 Tampermonkey 更新结果或重新加载原生扩展，再刷新领星页面 |
| 检查结果超过上限 | 改为近 7 天或近 30 天，必要时分批核对 |
| 提示订单状态已变化 | 按插件刷新后的待标清单重新核对，不要沿用旧截图或旧导出 |
| 提示确认清单已变化 | 重新执行一次“确认标注”，重新完成只读复核和人工确认 |
| 上次提交结果未确认 | 点击“回读上次批次”，不要在结果未确认时再次写 |
| 限流、超时或权限失败 | 插件会停止，不会自动重试；查看领星账号权限和网络状态后再人工处理 |
| 领星账号切换 | 插件会清空当前检查状态并重新检查；不要沿用另一个账号的清单 |

提交前或提交过程中不要同时打开两个标签页处理同一批订单，也不要切换领星公司账号。不同浏览器标签页之间没有共享的写锁。

# 数据与安全边界

- 页面通信层在把订单传给插件界面前，会剔除买家姓名、邮箱和地址；界面和本地记录不保存这些字段。
- 不保存 `auth-token`、Cookie、密码或请求头。
- 写请求只针对领星原生“标记推广”，每批最多 20 笔，且必须经过预复核和二次确认。
- 插件不绕过登录、权限或领星校验；页面会话失效时停止。
- 关闭或停用插件不会回滚已经提交到领星的推广标记；如需撤销，只能在领星原生界面人工处理。
- 需要排查时提供插件版本、操作时间、店铺/市场、订单号、提示截图和导出的执行记录；不要发送账号密码、Cookie 或令牌。

# 常见问题

**为什么 `Pending`、取消或退款订单也出现在待标清单？**

财务要求这些 Vine 订单进入推广订单，因此插件不按订单状态自动排除。仍需按订单号、店铺和 Vine 标识核对，再决定本批是否勾选。

**为什么 `isPromotion` 已有值，仍被列为待标？**

插件以 `isAssessed = 1` 判断是否已标，`isPromotion` 不参与最终判断。请以订单的回读结果和领星原生页面为准。

**每天会自动标注吗？**

不会。每日首次只自动做一次只读检查；标注必须由运营选择、确认并二次勾选。

**插件扫描的是当前筛选出的订单吗？**

不是。插件按所选日期范围重新读取销售订单全部分页，不受当前页面筛选影响。

**导出预览后，为什么还需要人工确认？**

CSV 只是核对材料，不提交领星。提交需要经过订单选择、提交前只读复核和确认弹窗。

**刷新页面会撤回刚提交的标注吗？**

不会。领星已经受理的写入不会因为关闭或刷新页面而自动撤回；如果页面中断，先按“检查记录”和回读结果核对。
