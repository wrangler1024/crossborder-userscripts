## 页面适配依据

- 领星 `ProductManageSku` / `ImportFile` 原生组件；复用 `$get`、`$gwPost` 请求层，不自行存取鉴权凭证。
- 店铺读取 `/api/seller/getCountrySeller`；Listing 读取 `/listing-api/api/product/showOnline`，精确 MSKU 数组和店铺 `sids`；商品详情 `/api/product/info`。
- 原生 SKU 更新模板使用 `产品` sheet，`*SKU` 为文本。仅勾选 `cg_package` 与 `cg_product_gross_weight`。
- 原生导入业务 `001001002`；入口 `/ak-import-center/erp/import/001/excel`。源码严格核对业务、路由、类型及选中字段，不匹配时停止。
- 64 位箱规 ID 保持字符串；遇到原生返回已丢失精度的数字则拒绝使用。
