# FBA 包装数据维护助手 操作文档

适用组件：0.1.5。更新日期：2026-11-16。面向负责领星商品资料维护的运营人员。

## 用它完成什么

把亚马逊费用预览报告中的包装长、宽、高和重量，批量维护到领星 ERP 已配对的本地商品，减少逐个查询和手工录入。

默认采用“按报告更新”：已有包装数据也会按报告生成差异，确认提交后更新这四项。已有数值四项一致的商品不重复更新。单品净重、商品本体规格、外箱资料和成本不在本次更新范围。

维护结果可为后续发货计划引用商品重量、尺寸提供参考。它是单件销售包装数据，实装外箱仍需按实际装箱核对；已有发货计划不因维护商品档案而被插件自动回填。

## 安装和升级

### 油猴版

1. 在使用领星的浏览器安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开[助手一键安装链接](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/lingxing-package-data-assistant/lingxing-package-data-assistant.user.js)，在 Tampermonkey 安装确认页选择安装；已有同一脚本时选择更新。
3. 若浏览器或 Tampermonkey 提示启用用户脚本权限，按当前浏览器的提示完成。安装后刷新领星页面，在商品管理页打开“FBA 包装数据维护助手”，核对窗口版本。

0.1.4 或更早的旧版，需要先通过上述链接覆盖升级一次到含自动更新配置的版本。之后保持 Tampermonkey 的脚本更新检查及自动安装更新开启，后续新版无需反复下载安装。检查周期按你的 Tampermonkey 设置执行，并要求能够访问 GitHub；程序更新后刷新领星页面生效。

需要立即获取已发布新版时，可在 Tampermonkey 管理面板对该脚本执行“检查更新”，按提示完成更新后刷新领星。若仍停留旧版，先查看脚本设置中的更新地址是否仍被手动覆盖为旧固定版本地址，必要时通过一键安装链接再次覆盖更新。[更新机制说明](https://www.tampermonkey.net/documentation.php?locale=en&q=update_url)

### 原生扩展版

从 [GitHub Release](https://github.com/wrangler1024/crossborder-userscripts/releases) 下载本助手的扩展 ZIP，解压后在 `chrome://extensions/` 打开开发者模式，选择“加载已解压的扩展程序”，加载直接包含 `manifest.json` 的目录。

原生扩展仍采用手动升级：替换原加载目录文件，在扩展管理页重新加载，再刷新领星页面。油猴版和原生扩展版选择一个启用，避免重复入口。

## 准备费用预览报告

在亚马逊卖家后台切换到正确店铺和站点，进入费用预览报告（Fee Preview）下载入口。常见路径为“数据报告 / Reports → 亚马逊物流 / Fulfillment → 付款 / Payments → 费用预览 / Fee Preview”；菜单名称随站点和后台版本可能不同，可在后台搜索 Fee Preview。

下载最新可用的原始 TXT 或 CSV；助手也支持 TSV、XLSX。保留原始表头、SKU、ASIN、FNSKU、三边、重量和对应单位，不将截图或人工重新拼接的表当作原始报告。文本编码或身份列被表格软件改写时，优先重新下载原文件。

每批对应一份报告和一个具体领星店铺，最多 500 条数据，文件不超过 20 MB。大报告可按店铺、站点或批次拆分，拆分时保留表头和身份列文本格式，不改变数值及单位。

报告日期用于记录数据来源，不是仓库测量时间。费用预览是报告快照，不能据此确认所有行都是刚刚实测的数据；包装方式或套装数量已变化时，先核对报告是否仍对应当前商品。

## 导入并核对配对

1. 登录领星，进入“产品管理”的按 SKU 商品页面，打开右侧助手入口。
2. 点击“导入费用预估报告”，选择报告所属的具体领星店铺，填写报告日期并选择文件。
3. 点击“解析并匹配”，等待助手读取 Listing 配对和本地商品现值。
4. 核对商品名称、图片、报告 MSKU、本地 SKU 和 ASIN/FNSKU。MSKU 与本地 SKU 可以不同，助手使用领星已有配对关系定位商品，无需手填对应表。

如未配对，先在领星完成该 Listing 与本地商品的配对，再在助手中“重新匹配”。不要为了匹配，把 MSKU 改成本地 SKU。若 ASIN/FNSKU 不符或出现多个候选，先核对领星与报告身份信息。

## 阅读商品差异

商品列表的四项筛选固定为一行：

| 筛选 | 代表什么 | 如何处理 |
| --- | --- | --- |
| 全部 | 本批所有记录，也包含“四项数值一致” | 查找商品、检查完整批次 |
| 可更新 | 可补全或可按报告更新的本地商品 | 核对本次更新后数值及勾选范围 |
| 待处理 | 未配对、身份冲突、来源冲突、箱规或单位待核对等 | 按具体提示处理后重新匹配或确认来源 |
| 已跳过 | 报告中的已识别其他站点行 | 不参与当前批次，到对应站点店铺处理 |

“可更新”的条数按合并后的本地商品计算，不一定等于报告行数。同一本地商品被多个 MSKU 配对时只更新一次；来源值不同会要求“选择来源”，需要选择一组完整数据。

右侧“包装资料对比”依次展示目标字段、领星当前值、亚马逊费用预估原值及本次更新后数值。目标单位统一为 cm、g。报告最长边、中间边、最短边对应包装长、宽、高。

例如，一份报告中某 MSKU 为 `DEMO-AMZ-001`，领星已配对本地 SKU 为 `DEMO-LOCAL-001`，报告三边为 8 × 4 × 1 in、重量为 0.2 lb，则换算目标为 20.32 × 10.16 × 2.54 cm、90.7185 g。此例仅演示换算，不能直接用于真实商品。

## 选择更新方式和默认箱规

“按报告更新”会以报告为准更新上述四项，适用于纠正缺失、盲录或旧资料。“仅补全”只处理四项全部为空或 0 的商品；已有部分数值的商品会提示切换模式核对，不会只补某一个空字段。

单一默认箱规可直接显示目标。一个商品有多套箱规时，按提示确认唯一默认箱规是否对应当前销售包装；无法明确默认目标时先回领星核对。助手不维护非默认箱规。

库存计量单位为空、报告毛重低于 ERP 既有净重，不影响本次按报告回填；净重仍保留原值。若后续业务需要净重资料，应另行维护，不能把本次包装重当作净重批量覆盖。

其他站点行被跳过，不等于一个共享本地商品会按站点保留多套尺寸。核对配对后再选择采用的数据来源。

## 确认并提交

1. 核对左侧勾选商品。解析完成后可更新商品会自动勾选，请取消不需要维护的商品；切换模式后再次检查选择范围。
2. 点击“确认更新”，核对目标店铺、报告日期、更新模式、商品数量和四项更新值。
3. 勾选“已核对选中商品及本次四项更新值”，点击“提交更新”。
4. 等待原生导入和商品读回核验，查看结果页面。

提交前若提示配对、箱规或现值已经变化，返回重新匹配并核对本批。程序不会以旧预览继续提交。原生导入已经接收后，暂停等待或刷新页面都不会撤回该任务。

## 查看结果与处理待核实

“成功”表示读回的四项值、单位和其他规格快照符合本批目标。原生任务已创建、上传完成或接口受理，不能单独作为成功依据。

如果显示“结果待核实”：

1. 打开“更新记录”，查看本批来源、原生任务编号和商品提示。
2. 在领星检查原生导入结果及本地商品现值。
3. 点击“重新核验”。该操作只读取现值，不会再次上传文件。

待核实商品会阻止再次提交。不要通过清理浏览器数据绕过；如果仍不能确认，把执行记录和原生结果交给维护人员核查。已成功的行不会因为其他行待核实而自动回滚。

本地记录在当前浏览器保存。未提交的报告预览刷新后需要重新导入；已保存执行记录可在原账号下查看。切换账号后按提示刷新，不能沿用旧账号批次。

## 导出及常见问题

可导出全部差异预览、待处理清单、已选商品的七列原生更新表，以及执行结果 JSON。导出更新表之前仍会检查配对和现值；下载文件本身不会提交 ERP 更新。清理领星站点数据前，按需保留原报告和执行记录。

| 提示或现象 | 处理方式 |
| --- | --- |
| 文件编码或标识无法识别 | 重新下载亚马逊原始 TXT/CSV；必要时导出 UTF-8，确认 MSKU、ASIN、FNSKU 未变为数字或科学计数法 |
| 在所选店铺未找到 MSKU | 检查报告所属店铺、站点和领星 Listing 同步情况 |
| 未配对本地商品 | 在领星完成已有 Listing 配对，再重新匹配 |
| ASIN/FNSKU 不一致或多个候选 | 核对报告与领星身份，处理完成后重新匹配，不手工替换对应关系 |
| 默认箱规、规格单位模式待核对 | 回领星检查默认箱规及单位模式，再重新匹配 |
| 其他站点已跳过 | 本批不用处理，选择对应站点的店铺后另建批次 |
| 四项数值一致 | 无需再次维护，可在“全部”查看 |
| 图片为空或加载失败 | 助手保留占位图；按名称、MSKU、本地 SKU 和 ASIN/FNSKU 核对，图片本身不作为身份匹配依据 |
| 账号变化或另一窗口正在处理 | 按提示刷新或等待原批次完成；先检查执行记录 |
| 未显示入口或更新后仍是旧版 | 确认当前为领星商品管理页、所选安装渠道已启用；刷新页面并检查 Tampermonkey 更新结果或原生扩展版本 |

反馈异常时提供：助手版本、所属店铺和站点、出现问题的 SKU、提示截图、操作步骤和必要的执行记录。账号密码、Cookie、令牌不作为排查材料发送。
