# Xynigo 验证码解题助手图标

## 视觉语义

- `3×3 九宫格`：SHEIN nine-captcha 的真实业务形态。
- `包裹黄格子`：模型判定需要命中的目标。
- `珊瑚红勾`：验证完成、结果带回。
- `深海军蓝圆角底 + 小犀青`：与 Xynigo 主品牌保持家族感。

图标不复用 Web 的 X 字标、Xyni 吉祥物、采购包裹或采购助手放大镜，避免不同扩展在 Chrome 工具栏中混淆。

- `icon32.png`：高分屏工具栏。

- `icon128.png`：扩展安装/管理大图标。

## 生成方式

使用 Codex 内置 `imagegen` 生成主稿，再仅做透明背景提取、透明边缘正方形裁切与尺寸缩放。主稿关键约束：单一图标、强轮廓、16px 可读、无文字、无 X 字标、无吉祥物、无放大镜、无水印。
