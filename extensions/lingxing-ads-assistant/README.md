# 领星广告创建助手

本地开发版本：0.9.2（未发布），2026-11-11。线上稳定版仍为0.9.1；本轮不推送更新入口、tag或Release。Chrome / Ego 与油猴共用源码。

0.9.2本地版在旧广告页`/ad_report/*`显示“广告创建助手”，点击同标签页跳新版SP页并自动打开面板。后续刷新不重复弹出；旧页只挂轻量入口，不初始化Excel、会话捕获或业务存储，不读取或创建广告。

本目录是开发权威源。运营使用[油猴一键安装](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/lingxing-ads-assistant/lingxing-ads-assistant.user.js)，首次需安装 Tampermonkey；本地开发继续在 Ego 扩展管理中加载 `dist/extension`。当前已发布0.9.1的 [Chrome 安装包](https://github.com/wrangler1024/crossborder-userscripts/releases/tag/lingxing-ads-assistant-v0.9.1)随 GitHub Release 发布。适配与更新机制见 [双渠道发布](USERSCRIPT_ROADMAP.md)，当前状态见 [开发交接](HANDOFF.md)。

支持 Excel 导入、商品及库存校验、建议竞价、当前预览编辑、本地恢复，以及确认后的批量创建。运营点击“创建广告”后，先核对活动、日期、状态和预算，再明确确认提交。导入、校验、刷新建议价和恢复预览本身不会创建广告。

安装包：`dist/领星广告创建助手-v0.9.2-Chrome本地扩展.zip`；已加载本地开发目录的浏览器使用 `dist/extension`。详见[安装与使用](使用说明.md)。原生扩展不需要篡改猴；两种版本都无需 MCP、API 密钥或独立服务。

## 操作流程

1. 更新本地目录后，在 `chrome://extensions/` 重新加载扩展，再刷新领星页面。
2. 点击右侧贴边“广告”入口，或从浏览器扩展菜单选择“打开当前页助手”，导入或恢复预览。
3. 核对商品、库存、建议价、关键词及自动投放勾选；需要时刷新报价。
4. 点击“创建广告”，等待批量创建功能权限、实时库存、广告资格和同名活动检查。
5. 勾选本次活动，选择开始日期（站点当地日期）和创建后状态。默认“暂停”；选“启用”后活动可能在整批完成前开始消耗。
6. 点击明确标注数量及状态的确认按钮。助手按活动逐条提交，并保存执行记录。
7. 等待自动回读或点击“检查创建结果”。查看逐活动状态、活动 ID；需要时导出创建记录。

## 页面入口

0.8.3将右下角大按钮改为右侧22px贴边入口，默认位于页面中部，避开底部分页。悬停或键盘聚焦时展开“打开/隐藏”，离开后收拢。点击“广告”直接打开；上下拖动可换位置，也可用上下方向键、Home/End调整。

“隐藏”会完全移除页面入口；浏览器扩展菜单仍可直接打开当前领星页面的助手，或重新勾选“显示页面侧边入口”。位置和隐藏偏好单独保存在本机，刷新后保留；不改变已有预览和创建记录。打开助手时侧边入口自动隐藏，收起后恢复原偏好。

## 账号准备

扩展入口打开SP广告列表，不直接跳转需要独立权限的超级结构页。商品预览读取当前账号可见的Listing；批量创建还要求角色拥有“广告 → 超级结构 → 查看、编辑”权限。普通SP创建权限不能代替超级结构权限。

如果原生创建SP活动的商品选择器也搜不到MSKU，管理员应核对店铺权限、Listing负责人和广告系统的数据权限。启用“自动应用Listing权限并匹配广告活动”时，广告数据范围由ERP Listing权限同步覆盖，应修正来源，而非反复导入Excel或单独临时扩大广告范围。

## 固定模型与预览来源

| 站点 | 每活动平均日预算 | 组默认价 / 无有效建议区间备用价 |
| --- | ---: | ---: |
| CA | CAD 4 | CAD 0.40 |
| AU | AUD 4 | AUD 0.40 |
| AE | AED 10 | AED 1.00 |
| UK | GBP 2 | GBP 0.20 |

- 一个父产品选一个主推子体，每活动一个广告组、一个广告商品。FBA 可售库存至少 10 件。
- 自动默认四类全选，预览可取消。关键词仅 BROAD、最多 5 个；商品仅扩展 ASIN、填写时 3–5 个。手动渠道留空可只创建自动广告。
- 有有效建议下限时取下限 ×90%，向下保留两位小数，不按预算的 1/10 封顶。成功查询但无区间时用备用价；查询失败不冒充无建议价。
- 动态竞价只降低，广告位和受众加价均为 0。名称使用 MSKU、渠道和固定导入时间。
- `finalPreviewPlans` 同时供预览导出与创建使用。剔除词、添加词、自动勾选和现有逐目标竞价都进入当前创建清单；不会重新从原始 Excel 拼装另一份目标清单。
- 自动广告提交全部四类定位，未勾选的类型明确设置为暂停，避免平台自动生成后启用。当前预览没有任何选中类型时不创建该自动活动。
- 固定模型参数不接受任意预算、策略、加价或其他投放类型覆盖。提交前再校验本站原生金额范围。

## 导入与保存

使用空白 `assets/广告创建详细参数模板.xlsx`。前五列为店铺、MSKU、ASIN、KEYWORDS、TARGET_ASIN，后三项中 ASIN 必填、后两列选填。其余详细参数保留默认值；`STATUS=仅预览` 表示导入阶段不直接执行，真实活动状态在创建窗口另选。兼容旧五列格式。

预览按领星企业、用户和区域隔离，原生版保存到 `chrome.storage.local`，油猴版保存到领星站点 IndexedDB，刷新后恢复导入工作表、报价、手动修改和命名时间。恢复不会自动发起建议价重试或创建。多页写入采用版本检查，旧页面不能覆盖新预览。单份预览上限 4MiB。

创建记录单独保存，清除预览不会清除它。提交前先持久化状态，再发送请求；两个标签页同时操作同一活动名称时只允许一个请求进入提交。已提交、结果不明、后台失败或已完成的记录不能再次发送。仅“尚未提交”的活动可以复核后继续。保护范围是本机同一安装渠道及领星账号；两渠道存储独立，跨电脑、跨渠道未迁移或清除数据后仍须核对领星记录。油猴版的跨标签互斥使用 Web Locks，缺少锁或持久化失败时停止创建，不降级为无保护执行。

## 本地备份与渠道切换

0.9.0 起可“导出本地备份 / 导入本地备份”，合并创建记录并恢复预览、建议价和手动调整。先在原渠道导出，停用该渠道并刷新领星，再在新渠道使用同一领星账号导入。原生旧版需先覆盖到0.9.0并重新加载，不能卸载后再找记录。备份属于内部业务文件，不上传公开仓库。

导入只接受当前账号且内容校验通过的备份。同名不同负载会拒绝，已提交状态不会被降低；可能已发出的任务恢复后先核实，不自动再次创建。油猴更新不清理 IndexedDB，但清除领星站点数据会删除油猴记录；原生卸载会删除扩展记录。建议定期导出备份。

两种版本选一种运行；新版本有页内重复启动拦截，但两渠道不是共享数据库，不能借此在不同标签页混用创建。

## 执行结果与中断

- “后台创建中”仅表示领星受理，尚不代表亚马逊所有对象创建完成。
- 回读结构和创建日志，核对活动 / 组 ID、广告商品 ID、全部投放目标 ID、日期、金额、匹配方式和启停状态，才显示“已完成”。
- 已发请求超时、页面刷新或回执无法识别时保留“提交中 / 结果待核实”，不自动重发。通过“检查创建结果”查询；归属或配置仍不明确时显示待人工核对。
- “停止后续提交”不会撤销已经发送的请求；后台已受理任务继续执行。请求未发出的活动仍可下次复核后选择。
- 平台限流显示等待提示，暂停继续发送；创建写请求不会按建议价重试队列自动重试。
- 本版不自动修补失败对象，也不提供批量删除、归档、调整已有活动或自动绑定兜底规则；后台部分失败应到领星“超级结构”的创建日志处理，避免重建整套造成重复。
- 提交后串行查询结果，每轮结束间隔 10 秒，最多 12 轮；之后仍可手动检查。期间保存的创建记录不会因关闭窗口丢失。

## 代码与接口

| 模块 | 职责 |
| --- | --- |
| `model.mjs` / `template-spec.mjs` / `workbook.mjs` | 导入、模型、Excel 与导出 |
| `preview.mjs` / `refresh.mjs` / `retry.mjs` | 当前预览目标、建议价及有限重试 |
| `client.mjs` | 当前页面会话与固定读取端点 |
| `persistence.mjs` | 明确业务字段的预览快照与恢复 |
| `execution.mjs` | 预览到原生负载、复核、串行执行、结果比较 |
| `execution-client.mjs` | 原生查询、批量创建和执行记录客户端 |
| `execution-ui.mjs` | 活动选择、确认、停止、回读和结果导出 |
| `extension/storage-service.mjs` | 预览版本检查与创建记录原子认领 |

原生创建端点为 `/pb-newad-web/v2/build/super/create/batch_create`，每个请求只提交一个活动及其一个组 / 主推商品。其余新增端点仅用于商品广告资格、同名活动、结构和创建日志查询。会话信息仅在页面内存中复用，不写入存储、文件、导出或日志。Manifest 只申请 `storage`，无 cookies / tabs / 全网站权限。

## 验证范围与局限

自动测试覆盖参数与目标传递、库存 9/10、资格及同名检查、两页并发、写前持久化、超时不重发、中断恢复、结果逐项核对和限流。完整报告及本机验收材料保存在忽略目录 `evidence/v0.8.0/`。

原生批量创建负载由当前领星前端代码、原生预览请求和历史创建结构交叉核对；读写适配通过模拟接口测试。0.8.0开发期间没有确认创建真实广告。用户随后提交首批3款共9个活动；0.8.1已回读核实9活动、9广告组、9广告商品及36个投放目标均创建完成，全部活动暂停，配置与提交预览一致。

加拿大、英国已验证商品读取与三活动预览；AU / AE 尚待当前账号可见广告账户上的联调。价格建议来自 ERP 返回值；扩展 ASIN 使用当前 50 个商品推荐池，不在池中不等于全平台无报价。竞品相关性、未返回的父子关系及原生权限仍由运营核对。

## 构建与版本管理

本目录作为 `crossborder-userscripts` 的独立模块维护；仅跟踪代码、测试、构建脚本、公开说明、空白模板和固定版本依赖。`dist/`、`evidence/`、真实运营表格、样本和导出结果不纳入 Git。

下列命令在本目录执行。仓库根目录对应入口为 `npm run test:lingxing-ads`、`npm run build:lingxing-ads`、`npm run release:lingxing-ads`。源码迁移不改变已安装扩展的路径或本机存储，后续更新仍需显式安装或重新加载。

```sh
npm ci
npm test
npm run check:userscript # 检查提交产物；必须在重新生成前运行
npm run build:all
npm run release
# 生成包含快速指南、空白模板及反馈模板的运营试用包
npm run release:trial
```

开发环境使用 Node.js 22、npm 10 和 Python 3；测试使用锁定版本的 fake-indexeddb 和 jsdom；业务构建不依赖运行时 npm 服务。固定 SheetJS 0.20.3 随库保存，SHA-256 为 `cc015130aa8521e7f088f88898eba949ccdcbfb38df0bd129b44b7273c3a6f41`，许可证见 `vendor/LICENSE-SheetJS.txt`。原生扩展使用随包资源。油猴从同仓固定版本tag加载完整程序，经SHA-256校验后缓存；不引用浮动main程序或第三方CDN，未通过校验不执行。两版均无独立后端。

0.8.0 新增确认执行及创建记录。0.7.1 的紧凑预览、0.7.0 的本地恢复、0.6.x 的建议价自动重试保持；预览数据模型版本未变，可恢复 0.7.x 已保存数据。

0.8.1修复结果误报：原生结构返回数字1/2，提交负载使用字符串"1"/"2"，比较时仅归一化这两个有效类型；实际自动/手动类型、金额、目标或状态不符仍保持待核对。已有记录可通过“检查创建结果”重新判定，不再次提交广告。新增两项回归测试，合计116项通过。首批核验材料见`evidence/v0.8.1/`。

0.8.2修复子账号入口与误导性报错：入口改为SP广告列表；商品空结果明确提示检查当前账号的Listing数据权限；每次创建检查和提交前均重新读取超级结构查看、编辑权限，缺少时不发送写请求。新增3项回归测试，合计119项通过。ERP权限需由管理员按业务范围配置，插件不会替用户授权。英国运营子账号在完成原生权限配置后已通过3款商品、9活动预览及全部创建前检查，本轮没有提交真实广告。

0.8.3调整贴边入口与扩展弹窗，新增入口偏好读写和当前页打开通信，Manifest仍仅申请storage。新增6项测试覆盖设置隔离、并发保存、来源校验、隐藏后恢复入口和错误提示；广告模型及数据版本保持。
