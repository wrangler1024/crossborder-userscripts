## 本地开发 0.9.2（未发布）

- 用户要求旧版领星广告页增加入口，点击跳新版SP并打开助手；后续明确“先不发版”。本轮只保留本地源码、生成物、测试包与Git候选，不推送main、tag、Release或线上更新地址。

- 148项测试通过，覆盖生成油猴旧页启动、轻量原生旧页、标记一次消费/过期/存储失败、两渠道实际生成程序的自动打开且零业务请求，以及原有导入、预览、创建与回读。只读生成检查、双构建、两ZIP完整性检查通过；用户脚本安装入口仍小于4KB。

## 独立开发

环境：Node.js 22、npm 10、Python 3。模块不依赖本机绝对路径、不依赖旧项目目录，无独立后端。新工作区按仓库 CONTRIBUTING 执行 `npm ci` 和 `npm ci --prefix extensions/lingxing-ads-assistant`，再运行：

```sh
npm run check:lingxing-ads:userscript
npm run test:lingxing-ads
npm run build:lingxing-ads
npm run release:lingxing-ads
```

也可进入本模块执行 `npm test`、`npm run build`、`npm run release:trial`。生成目录 `dist/` 被 Git 忽略；不要直接改生成文件。
