# 领星广告创建助手 运营试用

版本：0.9.7。适用：Chrome、Ego 桌面浏览器。先用少量商品走通导入、预览、创建和结果核对，再逐步增加批量。

## 油猴版（运营日常使用）

先安装并启用 Tampermonkey，按其提示允许用户脚本，再点击[广告助手一键安装](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/lingxing-ads-assistant/lingxing-ads-assistant.user.js)并确认安装。后续由脚本管理器按设定周期检查更新，也可从油猴菜单主动检查；固定链接无需每次更换。

已有原生扩展先更新到0.9.0，导出本地备份。停用原扩展、刷新领星，再在油猴助手导入备份。两版存储独立，不能同时混用；备份包含预览和创建记录，不只导出竞价表。油猴数据在本机领星站点存储，清理站点数据前须备份。

## Chrome / Ego 原生扩展安装

1. 把试用 ZIP 解压到固定位置，例如 Windows 的 `D:\领星广告创建助手`，或 Mac 的“文稿/领星广告创建助手”。
2. 在浏览器地址栏输入 `chrome://extensions/`，打开“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择解压目录里的 **插件** 文件夹。这个文件夹里应能看到 `manifest.json`。
4. 正常登录领星，进入广告系统的SP广告列表，刷新页面，点击右侧蓝紫圆形入口，或从浏览器扩展菜单选择“打开当前页助手”。

安装后保留这个文件夹。已有旧版时，把新版“插件”文件夹内的文件覆盖到原安装目录，在扩展管理页点击重新加载，再刷新领星页面；沿用原目录和扩展即可保留本机预览与创建记录。

侧边入口可以上下拖动，悬停展开后的三点菜单可隐藏入口；隐藏后仍能通过浏览器扩展菜单打开。位置与显示偏好会保存在本机。

## 先确认本人账号可用

领星原生“创建SP活动”中应能搜索到本店主推MSKU。批量创建还需要“广告 → 超级结构”的查看、编辑权限；看不到商品或提示缺少权限时，请管理员核对Listing负责人、广告数据范围和角色功能权限。重新安装插件或反复修改Excel不能补齐ERP权限。

## 第一批先选 3 款商品

打开包内“广告创建详细参数模板.xlsx”，在“广告导入”页每行填一个主推子体，其他默认参数保持原样。

| 字段 | 填法 |
| --- | --- |
| 店铺 | 从领星广告页面复制完整店铺名 |
| MSKU | 当前店铺的主推子体 MSKU；一个父产品只选一个子体 |
| ASIN | 与该 MSKU 对应的子 ASIN |
| KEYWORDS | 选填，1–5 个广泛词，单元格内每行一个 |
| TARGET_ASIN | 选填，3–5 个相关畅销商品 ASIN，单元格内每行一个 |

关键词或扩展 ASIN 留空会跳过对应手动活动；只填前 3 列即可生成自动广告。0.9.3起允许FBA可售库存0–9件预览并创建暂停活动；直接启用仍需至少10件，到货后手动开启。已有详细模板可继续使用；`STATUS=仅预览` 保持原样，真实活动状态在创建窗口选择。

## 导入到创建

1. 选取 Excel，点击“校验并生成预览”，核对商品、库存、活动和竞价。可剔除或添加关键词、调整自动类型勾选；当前预览就是创建依据。
2. 建议价未返回时可点“刷新”，也可等待有限次数的自动重试。成功查询但没有区间会显示备用价；接口报错的渠道等待处理。
3. 点击“创建广告”，等待库存、广告资格和同名活动检查；勾选本次需要的活动，核对日期、状态和日预算。
4. 首次试用建议保留默认“暂停”后确认创建。需要直接投放时，可明确选择“启用”；启用后即可能产生消耗。
5. 等待“已完成”，或点“检查创建结果”。到领星“结构 → 超级结构”查看对应创建日志；暂停活动需在领星启用后才会投放。

每个活动一个广告组、一个主推商品。加拿大 CAD 4/日，澳大利亚 AUD 4/日，阿联酋 AED 10/日，英国 GBP 2/日；三活动全开时按三个活动累计预算。

有建议区间下限时，起始竞价取下限 ×90%，向下保留两位。成功查询但无区间时，用单活动日预算 ÷10；广告组默认价同样为日预算 ÷10。

## 结果、恢复与反馈

- “后台创建中”表示领星已受理，稍后检查；“已完成”表示对象和配置回读通过。
- “待人工核对 / 结果待核实 / 创建失败”时，先检查领星日志和已有记录，不重新导入另建一批同样商品。
- 导入数据、建议价和手动调整会保存到本机；刷新后打开助手可恢复。“停止后续提交”只停止尚未发送的活动。
- 本机记录不会自动同步到另一台电脑。出现问题时使用包内“试用反馈模板.txt”，附截图；涉及创建结果时附“导出创建记录”。
