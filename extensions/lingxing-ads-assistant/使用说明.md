# 领星广告创建助手 安装与使用

本地版本：v0.9.7（未发布），2026-11-11。线上安装链接仍为0.9.6。支持预览与批量创建、旧版广告页入口和零库存暂停预建；原生扩展和油猴版选择一种启用。

填写Excel后，助手读取当前登录账号可见的领星商品、FBA可售库存和建议竞价，按填写内容生成1–3个SP活动的预览。只填商品信息就预览自动广告，广泛关键词和扩展ASIN选填。核对预览后可点击“创建广告”，在确认窗口选择活动与状态，再批量执行。

## 油猴安装与升级

1. 在 Chrome 安装并启用 [Tampermonkey](https://www.tampermonkey.net/)，按其提示允许用户脚本。
2. 点击[广告助手一键安装](https://raw.githubusercontent.com/wrangler1024/crossborder-userscripts/main/scripts/lingxing-ads-assistant/lingxing-ads-assistant.user.js)，在脚本管理器页面确认安装。
3. 关闭原来的广告助手原生扩展，刷新领星广告页面。右侧蓝紫圆形入口或油猴菜单“打开广告创建助手”进入。
4. 保持脚本自动更新开启。升级频率由 Tampermonkey 设置决定，也可点其菜单“检查广告助手更新”。安装链接保持不变。

## 0.9.0安装页卡住的处理

先关闭旧的“安装/重新安装”页面，再打开一键安装链接，确认显示0.9.1或更高版本后更新。若Chrome完全无响应，结束无响应的Chrome后重新打开，避免恢复旧安装页。无需清除浏览器或领星站点数据；原有预览和创建记录保留。若更新仍卡住，先停用该脚本并使用同版原生扩展，将故障发生阶段和版本反馈给管理员。

## 原生扩展安装（Ego本地开发测试）

[下载0.9.6 Chrome包](https://github.com/wrangler1024/crossborder-userscripts/releases/tag/lingxing-ads-assistant-v0.9.6)。原生扩展无需篡改猴。

1. 将`领星广告创建助手-v0.9.7-Chrome本地扩展.zip`解压到固定目录。确认目录中直接包含`manifest.json`、`content.js`、`popup.html`等文件。
2. 在Ego或Chrome地址栏输入`chrome://extensions/`，打开“开发者模式”。
3. 点击“加载未打包的扩展程序”（有些版本叫“加载已解压的扩展程序”），选择刚才解压的目录，不能选择ZIP文件。
4. 确认“领星广告创建助手”的版本与本次安装包一致，并处于启用状态。无需API密钥或开发环境。
5. 登录领星，从ERP进入广告系统，打开“SP广告”列表，刷新页面。
6. 点击页面右侧贴边的蓝紫圆形入口；也可点击浏览器工具栏中的本扩展，选择“打开当前页助手”。

安装后保留解压目录，不能移动或删除。更新时覆盖原目录，在扩展管理页点本扩展的重新加载，再刷新领星页面。停用时关闭本扩展开关并刷新页面。

新版`https://ads.lingxing.com/amazon/*`运行完整助手；旧版`https://ads.lingxing.com/ad_report/*`仅显示跳转入口。导入和预览不会创建广告；最终确认按钮会向领星提交真实创建请求。

## 旧版广告页入口（0.9.2起）

旧版页面右侧显示蓝紫圆形入口，悬停展开“广告助手”，点击后在当前标签页进入新版SP广告页，并自动展开助手。原生扩展弹窗、油猴“打开广告创建助手”菜单也支持同一跳转。只自动打开一次，普通刷新不会重复弹出；不会自动校验或创建广告。旧页筛选的店铺与商品不自动映射到新版，请在助手核对导入表的店铺。

## 零库存提前准备（0.9.3起）

商品身份和Listing在售状态正确、库存明确返回0时，按正常流程校验并生成预览。建议价成功查询但无区间时沿用本币备用价；接口失败仍需重试，不伪装成无建议。商品清单在“可预览”右侧显示红色圆圈感叹号，悬停即时显示浮层“可售库存不足，仅可暂停创建”；键盘聚焦也可查看，移开、失焦或按Esc关闭。商品详情中的低库存提示以深红文字、浅红底色强调。

创建清单勾选了任意库存0–9件商品时，整批状态固定为暂停；取消这些活动的勾选后，其余库存合格活动可选择启用。提交前仍逐个复核库存和广告资格，选择启用的活动若库存下降到10件以下就停止该项提交，不静默改成另一状态。

到货后由运营核对库存并在领星手动启用，助手不自动开广告。旧版已保存的零库存“待处理”商品需要重新点一次校验，再生成预览。旧有创建记录继续保留，不能因更新重复创建。

## 侧边入口与隐藏

- 页面入口为46px蓝紫圆形按钮，紧贴页面右边缘；鼠标悬停时向左展开“广告助手”和三点菜单，圆形位置保持不动。
- 点击圆形图标或“广告助手”进入助手。拖动圆形图标可上下调整；键盘聚焦后也支持上下方向键与Home/End。拖动结束不会误开预览。
- 打开三点菜单并点击“隐藏入口”后，页面不再保留悬浮入口。仍可从浏览器扩展菜单点击“打开当前页助手”；勾选“显示页面侧边入口”可恢复。
- 入口位置和隐藏状态保存在本机，刷新后保留。打开助手时入口自动隐藏，收起助手后恢复原来的显示偏好。
- 在非领星页面点击“打开当前页助手”会提示先进入广告页；扩展更新后，旧领星标签页需刷新再使用。

## 填表

使用随包的`广告创建详细参数模板.xlsx`，或在插件中点击“下载详细模板”。在“广告导入”工作表填写前五列，每行一个主推商品。其余列保留默认值或留空。

| 前五列 | 填写要求 |
|---|---|
| 店铺 | 必填，复制领星广告页面完整店铺名称，不能只填国家 |
| MSKU | 必填，每个父产品一个主推子体，不用本地料号代替 |
| ASIN | 必填，与MSKU对应的10位子ASIN |
| KEYWORDS | 选填，填写时1–5个，单元格内每行一个；留空跳过关键词活动 |
| TARGET_ASIN | 选填，填写时3–5个不同种子，单元格内每行一个；留空跳过商品活动 |

100行默认参数已预填，没有填写商品的行不会被当作产品导入。需要更多行时可复制空白行，每工作表最多500款。不要合并单元格，公式整理的数据导入前粘贴为值。

兼容原五列中文表头，以及旧表的SITE、TARGET_ASINS。可加“父产品标识”用于同父查重。原详细表中缺少表头的工作表，需要先补齐表头。

“默认参数”页说明各字段和四站金额。参数列采用“按站点”“预算÷10”“自动计算”等默认规则，插件读取实际店铺和建议价后计算数值。首轮不使用旧表的手填竞价、类目和精准词设置；与当前默认模型冲突时会提示恢复默认或清空，不会悄悄覆盖。

每文件最多5MB，仅接收`.xlsx`。

## 生成预览

1. 点击“广告创建助手”，选择填好的Excel。
2. 核对工作表。多个工作表分别检查，不会自动合并。
3. 点击“校验并生成预览”，等待逐款读取完成。正在读取时可以点击“停止”。
4. 左侧选择商品，右侧核对图片、MSKU/ASIN、FBA可售库存、三活动名称、预算和逐目标竞价。
5. 查看每个渠道“可预览／已跳过／待处理”。部分预览保留有效渠道；输入格式问题需修正后重新导入；建议价读取失败可在当前预览中重试。商品身份或库存不通过会阻止整款。
6. 按需导出JSON预览或CSV竞价明细。它们用于核对，不是亚马逊批量上传文件。

导入数据、已获取建议价和手动调整会自动保存到本机对应渠道。等待说明行显示“已自动保存”后，刷新领星页面并打开助手即可恢复，无需重新导入校验。收起面板不会取消当前请求，后续自动重试暂停，再次打开后恢复。

## 从预览批量创建

1. 在预览中确认本次商品、关键词、扩展ASIN、自动勾选及逐目标竞价，点击工具栏“创建广告”。
2. 等待检查当前账号可见店铺、在售状态、有效FBA可售库存、商品广告资格及同名活动。未通过的活动不能选择，已提交名称不会再次发送。
3. 勾选本次需要的活动，核对日预算合计；支持只选自动广告或部分活动。
4. 选择开始日期（按店铺当地日期填写），创建后状态默认“暂停”。需要立即投放时明确改为“启用”；启用的活动可能在整批尚未结束时开始消耗。
5. 点击“确认创建…活动”。助手按活动串行提交，每个活动一个广告组和一个主推商品，以当前预览为准。
6. 查看“后台创建中 / 已完成 / 创建失败 / 结果待核实”。领星受理不等于创建完成；助手会继续查询实际活动、广告组、广告商品和目标，并核对配置。
7. 可点击“检查创建结果”再次读取，或“导出创建记录”保存结果和ID。领星后台可在“结构 → 超级结构”查看对应创建日志。

Excel的`STATUS=仅预览`继续保留，表示导入不直接执行。实际启停状态在上面的创建窗口统一选择，不需要修改运营已填表格。

自动广告未勾选的类型会明确创建为暂停；已勾选类型使用预览里的独立竞价。关键词只提交当前保留的词。接口失败的渠道不纳入可创建清单；成功查询但未返回建议价的目标仍使用已标明的备用价。

“停止后续提交”只阻止下一条，不撤销已发请求。领星已受理的任务会继续在后台处理。关闭或刷新后，本机创建记录仍在；再次打开“创建广告 / 创建记录”，先检查结果。提交超时、回执不明或后台部分失败均不会自动重发整套；请在领星日志核实后处理。尚未发送的活动可重新检查再提交。

创建记录与预览分别保存。“清除本地预览”不会删除创建记录。多标签页的同名任务不会重复发送；更换电脑、卸载扩展或清除扩展数据后，本机保护无法继续沿用，需要核对领星和已导出的创建记录。同名检查不代表已识别所有不同名字的重复广告。

若领星返回限流，按页面提示等待，再检查未提交项或已提交结果。广告创建写请求不参加建议价自动重试队列。提交后自动结果查询最多12轮、每轮结束后间隔10秒，尚未完成时可继续手动检查。

## 本地保存与恢复

- 导入、商品校验完成、建议价更新、关键词增删、自动目标勾选以及未提交的关键词输入都会自动保存。也可点击“保存预览”立即保存。
- 同一浏览器、同一领星企业及登录用户自动恢复最近一份预览，保留原始工作表和当前工作表的预览调整、图片链接、库存、逐目标建议价及其读取时间、活动命名时间。刷新不会产生新的命名批次。
- 恢复后可直接查看、编辑和导出；库存和报价是上次读取结果，需要最新数据时再点“校验并生成预览”或刷新本组建议。恢复时自动重试暂停，按需重新勾选，不自动反复请求。
- “清除本地预览”只清除当前账号的本机预览保存，当前页面数据仍保留，自动保存暂停。点击“保存预览”或重新导入后恢复保存。清除后刷新页面将没有这份预览。
- 多个页面同时编辑时，旧页面不能覆盖已经更新的本地预览；出现提示后先导出该页调整，再刷新加载最新结果。
- 只在本机保存，不上传云端；不保存领星令牌或会话头。原生卸载会删除扩展保存；油猴版清除领星站点数据会删除 IndexedDB 中的保存。更换电脑、浏览器或安装渠道不会自动同步。单份保存超过4MiB或空间不足会明确报错，旧保存保持，可导出后拆分表格。
- 首次从0.6.x升级时，旧页面内存中的预览不会自动迁移；先导出需要保留的调整，再刷新并导入一次。此后按本地保存状态恢复。

## 更换安装渠道和备份

旧原生扩展先原路径更新到0.9.0，在本人领星账号下点击“导出本地备份”。停用原渠道并刷新领星后，在新渠道点击“导入本地备份”，选择该JSON并确认。预览将替换，创建记录合并并保留更保守状态；同名内容冲突会提示停止。备份必须属于当前领星账号，不自动提交广告。

原生和油猴存储独立，不同时使用两种版本进行创建。日常升级保持原渠道、原浏览器即可保留本地数据；切换和清理浏览器前先备份。

## 在预览中调整投放

自动、关键词、商品卡片按01/02/03编号。投放行采用紧凑布局，建议下限和“刷新”同排；计价标签与获取时间并排，较长依据说明悬停可查看全文。已获取建议价也保留刷新入口；未勾选的自动目标不显示刷新。

### 自动重试建议价

工具栏的“自动重试建议价”默认勾选。首轮校验完成后，失败或未取得建议下限的广告类型按商品整组入队；已全部取得下限的组不重试。

顶部只显示一条进度提示，集中展示重试次数、当前步骤、目标数量和已用时。查询完成后的已获取/未返回数量、备用价说明及“预览调整已保留”也显示在这条提示内；等待下一次重试时保留本次结果，失败时保留具体原因。自动重试期间只显示条内的“停止重试”按钮。

自动重试提醒采用醒目的动态提示：等待时为橙色倒计时圆环和流动光条，最后3秒增强脉冲；正在重试时切换为蓝色旋转圆环，显示当前次数。编辑暂缓、完成或达到上限时改为静态状态；停止后隐藏提示。系统开启“减少动态效果”时保留静态颜色、计时和文字。

- 每组最多自动重试3次，不含首次读取和人工刷新；依次至少等待10、30、60秒。请求串行，自动查询之间至少间隔3秒；排队或接口限流可能使实际等待更长。
- 失败渠道优先；每次读取当前预览中的整组目标。删掉的词和未勾选的自动目标不再查询；成功补齐的组自动退出队列。
- 重试倒计时、正在重试的商品/广告类型和次数会显示在页面。达到上限后保留备用价或待处理状态，不无限循环，也不保证一定取得建议区间。
- “停止重试”或取消勾选会取消排队；若正在自动请求，也会中止。首轮校验或人工刷新时的顶部“停止”同时停止当前读取并关闭本轮自动重试。需要重新开启时再勾选，开始新一轮计数。
- 重新校验、重新导入、切换工作表会清空旧队列；账号切换会取消旧请求。输入错误、库存缺失和明确的登录/授权错误不会自动重试。
- 编辑关键词或查看放大图片时暂停后续自动请求，离开编辑区或关闭图片后继续。等待期间可核对预览和导出；导出内容是点击当时的当前清单。

这些重试只读取建议价，不创建或启停真实广告。

校验或刷新建议价时，顶部显示旋转图标、流动光条、当前步骤和已用时，当前商品卡片同步显示动态提示。已处理款数来自实际处理结果；光条表示仍在读取，不表示完成百分比。某一步等待较久会提示可随时停止。完成、失败或停止后动画结束。系统开启“减少动态效果”时使用静态提示，步骤和计时仍显示。

- 商品清单每张卡片显示可点击放大的商品缩略图，右下角显示已读取的FBA可售库存；尚未取得数据时显示“—”。库存0–9时在状态右侧显示红色圆圈感叹号，悬停说明暂停创建限制。
- 在“关键词”表点“剔除”移除不需要的词；在下方输入一个词，点“添加并获取建议价”。仍限最多5个，不接受空词、重复词或超过80字符的词。全部剔除后不生成关键词活动，预算合计同步减少。
- 自动广告默认四类全选；按需取消或重新勾选。只把勾选项纳入预览和导出，全部取消时不生成自动活动。
- 点击任意已选用目标建议下限右侧的“刷新”，会刷新当前商品、当前广告类型的全部预览目标，包括已有建议价的目标。自动广告只刷新勾选项，关键词只刷新当前词表。请求成功但仍无区间时继续用本币备用价；请求失败会显示待处理，并暂停该渠道的预览输出，重试成功后恢复。
- “校验并生成预览”会重新读取商品、库存和当前目标的建议价，保留本页增删关键词和自动勾选。切换工作表或重新导入文件会按原表重新读取；刷新领星页面会恢复已保存的当前预览调整。
- 活动数、预算合计、JSON和CSV均以当前预览清单为准。剔除词和未勾选自动目标不会出现在选用目标清单；创建时会将未勾选自动类型明确暂停。

关键词与商品规格、数量和用途是否一致仍需人工判断，例如2件装商品不应保留明确写3PCS的词。

商品卡片采用紧凑布局，“建议价待获取 N”与“可预览/部分预览”在同一行。它表示当前选用目标中有N个尚未取得有效下限。悬停可查看“未返回”与“读取失败/尚未读取”的数量；剔除词、未勾选自动目标不计入。使用备用价的活动仍可预览，标识提醒运营核对。

整组刷新只更新当前商品的当前广告类型，不跨商品或混合自动、关键词、ASIN查询。刷新时显示“正在查询本组全部N个目标”，完成后分别显示已获取和未返回数量；商品图片和其他渠道保持，滚动位置保留。

重复点击保护：一次查询完成后，本组按钮等待3秒再开放，这是助手的本地间隔保护。若接口明确返回HTTP429或限流业务错误，则按接口Retry-After等待；没有等待信息时，助手默认等待30秒。页面显示倒计时，期内不会再发该账户的建议价请求，到期后，开启自动重试时按队列继续；关闭时由运营手动重试。请求串行执行，不自动连发。普通超时、业务错误和查询成功但无区间会分别提示，不统一说成限流。

## 固定模型

| 站点 | 单活动日预算 | 组默认价／无有效建议价备用价 |
|---|---:|---:|
| 加拿大 | CAD 4 | CAD 0.40 |
| 澳大利亚 | AUD 4 | AUD 0.40 |
| 阿联酋 | AED 10 | AED 1.00 |
| 英国 | GBP 2 | GBP 0.20 |

- 一款1–3个活动，每活动一个组，每组一个主推商品。仅自动时合计为一个活动预算，两渠道为两倍，三渠道全填时为CAD 12、AUD 12、AED 30、GBP 6。
- 自动初始四类全选，可在预览逐项取消或重新勾选；手动关键词只用广泛；商品只用扩展ASIN。后两列留空就跳过，填写有误只阻止对应手动渠道，不挡住有效的自动预览。
- 主推MSKU仍必填，不根据ASIN猜测；模板的五个核心表头仍须保留。
- 有有效建议下限：下限×90%，不按日预算1/10封顶；同时显示原始结果和向下保留两位的预览竞价。
- 无有效区间：使用日预算÷10，并标明来源。接口失败或超时会报错，不冒充“无建议价”。
- 动态竞价只降低，广告位和受众加价为0；命名使用MSKU＋渠道＋本次导入时间。
- 有效FBA可售库存0–9件可生成预览、编辑目标并创建暂停活动；至少10件才允许直接创建并启用。空值、负数或无效库存仍拦截。

## 本版需要人工核对的项目

商品库存校验使用领星广告选品页返回的FBA可售数量。它不代表FBM或全渠道合计，也不代表完整广告投放资格已经通过。

扩展ASIN报价来自当前50个商品推荐池。输入ASIN不在池中，或对应扩展区间未返回时，会标注备用价。它不代表全平台都没有此ASIN的建议价，也不会借用精准投放的报价。

创建前会重新检查在售状态、FBA库存、商品广告资格、同名活动及本站竞价范围。父子关系缺失、不同名称的历史广告重复、关键词和竞品相关性仍需按SOP复核。活动命名加时间用于区分批次，不等同于去重或重新获得测试预算。

已在领星真实页面验证加拿大、英国商品；澳大利亚、阿联酋仅完成模型测试，待可见广告账户接入后验证。更新至当前版本并重新加载扩展后使用原模板即可。用户首批3款共9个活动已回读核实创建完成，全部暂停；0.8.1修复了广告类型数字/文本格式引起的“待人工核对”误报。更新后对已有记录点击“检查创建结果”，无需重建。

## 子账号权限准备

使用本人领星账号。批量创建需要角色功能权限“广告 → 超级结构 → 查看、编辑”；这与普通“SP广告 → 创建广告活动”是不同权限。助手会在创建检查和提交前读取当前权限，缺少时显示具体提示，不提交广告。

商品读取同时受店铺、ERP Listing负责人以及广告数据权限限制。若提示“当前账号可见商品中未找到完全匹配的MSKU”，先在领星原生“创建SP活动”商品列表搜索同一个MSKU；原生也没有时，请管理员核对数据范围。广告设置启用自动应用Listing权限时，应先核对ERP Listing负责人，避免临时广告授权随后被同步覆盖。

## 常见问题

| 提示 | 处理方法 |
|---|---|
| 看不到入口 | 确认已进入广告系统，本扩展已启用，并刷新页面 |
| 会话未就绪 | 等待领星原生商品列表加载，必要时刷新；不需要复制token |
| 找不到店铺 | 从广告页面复制完整店铺名，确认当前账号本来能看到该店铺 |
| 当前账号可见商品中未找到MSKU | 核对完整MSKU和店铺；原生选品同样为空时，由管理员检查Listing负责人及广告数据权限 |
| 缺少超级结构权限 | 管理员在角色功能权限中核对“广告 → 超级结构”的查看、编辑权限，更新后刷新领星再检查 |
| MSKU或ASIN不符 | 复制对应Listing的MSKU和子ASIN，不用本地SKU代替 |
| 库存0–9 | 可预览并暂停创建；到货且可售库存至少10件后，在领星手动启用 |
| 库存未返回或状态不明 | 先在领星核对真实商品状态，不能手填库存绕过 |
| 文件无法读取 | 将Excel保存在可访问的本地位置，再重新选择 |
| 查询失败、超时或Failed to fetch | 检查登录及网络后重新校验，失败不使用备用价 |

## 本地0.9.7 校验结果与未生成活动

商品卡片左下为“可创建 N/M 活动”，右下保留可售库存。M按当前选用的广告类型计算：只投自动时为1，三类全选为3；关键词或商品投放留空、手动取消自动不计入M。N为当前已生成的活动预览数，真实提交前仍检查权限、库存、广告资格和同名活动。

部分广告类型校验失败时显示“部分预览”。顶部汇总完整、部分预览及已生成/计划活动数，出现未生成活动时点击“查看明细”：右侧抽屉显示MSKU、广告类型、Excel工作表及行号和具体原因，每页10条，表头和分页固定，正文内部滚动。点击“定位”收起抽屉并显示对应商品和广告类型；再次打开保留当前页。

建议价成功查询但无区间、已使用备用价生成的活动不计为失败。查询失败、重复关键词、扩展ASIN重复或不足3个会列出原因；重试成功后计数和明细自动更新。
