# Xynigo SHEIN 安全批量上下架安装说明

版本：`2.0.0`

同一个 ZIP 可安装到 Google Chrome、HubStudio/Hub 浏览器以及其他支持 Manifest V3 的 Chromium 浏览器，不依赖 Tampermonkey。

> 这是会修改商品销售状态的高风险工具。当前版本只允许在测试店铺使用少量 SKC 和单一站点验收，暂不向运营批量分发。

## 安装

1. 完整解压 ZIP，不要直接从压缩包内部打开文件。
2. 在目标 HubStudio 浏览器环境中打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压得到的 `xynigo-shein-batch-shelf-v2.0.0` 文件夹；文件夹内应直接看到 `manifest.json`。
6. 登录 SHEIN 卖家后台，打开商品列表页并刷新。
7. 页面右上角出现“安全批量上下架”按钮即表示安装成功。

如果 Tampermonkey 中已经启用旧版或同名脚本，请先停用，避免两个版本重复运行。

## 首次验收

1. 使用测试店铺、3～5 个测试 SKC 和一个站点。
2. 分别验证指定 SKC 上架、指定 SKC 下架和已售罄下架。
3. 核对操作预览后，按页面要求输入“确认上架”或“确认下架”。
4. 执行结束后导出 CSV，并在 SHEIN 后台核对商品实际状态。
5. 页面显示“API 已受理”只代表接口明确返回 `OK`，不等于逐条状态已经复核。

## 更新

本地加载的扩展不会自动从 GitHub 更新。收到新版本 ZIP 后：

1. 解压并覆盖旧扩展目录，或解压到新的固定目录。
2. 回到 `chrome://extensions/`。
3. 在扩展卡片上点击“重新加载”。
4. 刷新 SHEIN 商品列表页。

不要删除浏览器当前加载的扩展目录，否则浏览器重启后扩展会失效。

## 开发联调

在仓库根目录执行：

```bash
npm run build:xynigo-shelf:dev
```

首次加载时选择固定目录 `dist/xynigo-shein-batch-shelf-dev`。后续重新构建并在扩展管理页点击“重新加载”即可。

## 权限与安全边界

- 扩展没有申请剪贴板、浏览历史、标签页、Cookie、下载或跨域访问权限。
- 仅在 `sellerhub.shein.com` 和 `sso.geiwohuo.com` 运行，并且只在商品列表路由显示入口。
- 预览阶段不会发送上下架写请求；必须选择站点、生成预览并输入确认词后才允许执行。
- 写请求只发送到当前 SHEIN 卖家后台的同源接口，不向第三方上传 Cookie、账号或商品数据。
- 当前没有可靠的批量状态查询接口，因此扩展不宣称自动验收或自动回滚。
