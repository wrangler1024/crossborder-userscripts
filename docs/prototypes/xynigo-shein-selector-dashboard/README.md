# Shein Global Selector 0.4.6 · 生产版静态原型

该页面已同步至生产版 `0.4.6` 的核心字段与翻页累计布局，只用于交互与信息架构评审；不会在 SHEIN 页面上执行真实筛选、导出或网络请求。

## 核心方案

- 不再占用 SHEIN 原生筛选区；入口改为吸附在页面右边缘的 `SHEIN选品助手` 悬浮按钮。
- 按钮形状对齐“解析商品型号”插件：展开态为 `154 × 44px` 浅色半胶囊，使用 42px 头像位与 46px 小犀图；默认向右收为 50px，只显示小犀头像。贴住页面的右边框保持垂直，左侧保留胶囊圆弧，明确表达磁吸关系。
- 鼠标悬停或键盘聚焦时，按钮自动向左伸长并显示 `SHEIN选品助手`；鼠标移开后自动向右收回。
- 整个按钮支持上下拖动，水平方向始终吸附右边栏；拖动后保存当前位置，窗口尺寸变化时自动限制在可视范围内。
- 单击按钮展开/收起底部工作台，拖动结束不会误触展开/收起；键盘聚焦后可用 `↑ / ↓` 调整垂直位置。
- 工作台上层使用带 28px 图标容器的单行紧凑工具带，顺序为 GlobalShip、QuickShip、Trends、New Arrivals、Sales、Price、Rating；宽屏时筛选卡自动扩展填满可用空间，窄屏时横向滚动。
- QuickShip 与 Trends 保留当前 SHEIN 前台实际图片资产的图形，但选品器内统一使用 Xynigo 品牌绿色；New Arrivals 官方集合页/排序项当前没有独立图片图标，原型因此使用 SHEIN 的 `NEW` 绿色标签视觉，不伪造官方资产。
- New Arrivals 使用新品闪光图标，Sales 保留递增销量柱。Price 卡片使用通用货币图标；优惠价签图标只属于 Coupon 字段，不再代表整个价格筛选器。
- Price 的币种代码与符号由站点配置驱动：墨西哥站显示 `MXN`，美国站显示 `USD`，不在组件里写死币种。
- 底部工作台统一 Xynigo 绿色 VI：品牌头图、扫描状态、筛选卡层级、焦点/悬停/选中反馈、表格选中边标与右侧概览区保持同一套视觉语言。
- Price 使用 `Min–Max` 金额范围，`Max` 留空代表无上限；优惠券提供 `65%`、`30%`、`0%` 快捷选择，`0%` 表示 No coupon，同时允许自定义 `0–100% OFF`。
- Rating 卡片使用更窄的宽度与内间距，提供 `All / 4.0+ / 4.2+ / 4.5+`；`All` 表示不限制星级。
- 右侧“官方字段扩展池”只是原型阶段的研究规划区，生产版不会原样展示；只有经过站点数据验证的字段才会转成正式列、筛选项或字段设置。
- 下层用表格展示商品 ID、页面价、券后价、销量、星级、Reviews、Listed on、规格结构、配送类型、卖家（Sold by）、官方信号和命中结果；Sold by 紧跟 Fulfillment，Product 与 Sold by 均支持横向拉宽。
- 商品以品牌绿色页分组栏展示，页分组栏固定在表头下方，支持“全选本页”。
- 右侧概览区展示漏斗数量与已选商品操作。
- 单行工具带末尾的最终命中/命中率概览压缩为 72px 并贴右对齐，优先把横向空间留给筛选器。
- 上架日期仅展示官方 `Novedades` 标识，不虚构近7天/近30天数据。

## 可交互项

- 页面右侧磁吸按钮默认只显示小犀头像，悬停/聚焦时伸长；点击展开/收起工作台，整体上下拖动调整位置。
- 拖拽工作台最上沿可上下调节窗口高度；聚焦拖拽条后也可用方向键、Page Up / Page Down、Home / End 调整。
- “最大化”使工作台铺满当前网页视口，“还原”恢复到最大化前的拖拽高度。
- 各筛选卡可独立开启/关闭。
- Sales 支持输入任意非负销量门槛，筛选数量随阈值演示联动。
- Rating 下拉为 `All / 4.0+ / 4.2+ / 4.5+`；`All` 恢复默认的不筛选状态，最高门槛为 `4.5+`。
- Trends 和 New Arrivals 对应 SHEIN 官方集合/标签信号，可分别开启；不把集合成员身份伪装成精确上架日期。
- Price 支持自定义金额区间、无上限 Max、`65% / 30% / 0%` 快捷券和自定义优惠券比例，表格券后估算价同步变化。
- 商品可单选或全选，已选数量同步更新。
- “复制商品链接”默认复制全部累计页面的筛选命中商品，按每行一条生成干净链接，不要求先勾选；快捷键设置中可改为“已选商品”。旁边的快捷键按钮可录入自定义组合键，原型默认 `Alt + L`，快捷键和复制范围保存在当前浏览器。
- “导出已选”始终只导出运营手动勾选的筛选结果，不受复制范围设置影响。
- “上一页 / 下一页”位于“重新扫描”旁边；第 1 页只累计第 1 页，第 2 页累计第 1–2 页，返回前页时移除更高页分组，页码、当前数、累计数和命中数联动更新。
- “重新扫描”有当前页状态反馈。
- “清空筛选”位于“重新扫描”之后，可一次关闭 GlobalShip、QuickShip、Trends、New Arrivals、Sales、Price/Coupon 与 Rating；同时清空金额、销量和优惠券输入，但保留已经勾选的商品。

## 评审重点

1. 右侧按钮与“解析商品型号”一致的 154 × 44px 胶囊比例、50px 头像收起态和悬停伸长交互是否合适。
2. 默认 460px、高度拖拽、全屏最大化三种工作台状态是否足够；单行筛选区会优先把垂直空间留给商品表格。
3. GlobalShip 与 QuickShip 同时开启时采用“任一匹配”还是互斥切换。
4. Sales 自定义输入是否需要常用值快捷按钮。
5. Price 的金额范围和 `% OFF` 定义是否符合运营输入习惯。
6. 翻页是驱动 SHEIN 官方分页，还是由插件维护跨页扫描队列。
