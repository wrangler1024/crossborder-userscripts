# 领星 Vine 推广标注助手 · 插件窗口原型

直接打开 [index.html](./index.html) 即可查看，不需要安装依赖或启动服务。

视觉与组件语言对齐项目内以下两个插件：

- 领星广告创建助手：冷灰蓝工作区、深色导航、白色工具栏、清晰的状态与操作层级。
- FBA 包装数据维护助手：深色渐变窗口头、冷灰紫面板、步骤条、左右分栏、底部批量操作栏。

## 原型范围

- 只用于交互和视觉评审。
- 不连接领星，不读取真实订单，不提交任何标记。
- 使用 2026-11-16 的检查结果作为演示数据：近 30 天 291 笔订单、67 笔 Vine、64 笔已标、3 笔待标。

## 已确认业务口径

1. 订单一出现就标，包括 `Pending`。
2. 已取消、退款状态的 Vine 订单仍标。
3. 推广类型保持默认，不新增 Vine 类型，不填写推广费用。
4. 插件只调用“标记推广”，不修改订单状态、备注和其他费用。

## 可交互项

- 左侧搜索、市场筛选与右侧订单表联动。
- 勾选或取消勾选待标订单，底部数量同步变化。
- 点击“立即检查”或“重新检查”查看扫描过程。
- 点击“确认标注”打开二次确认；勾选核对项后提交，查看进度和回读成功状态。
- 成功后可导出本次标注记录 CSV。
- 点击右上角 `—` 或 `×` 收起为右下角启动按钮，再点击恢复。
- 点击“检查记录”查看最近检查历史。

## 后续接入建议

生产版建议沿用当前窗口结构：

1. 自动检查，但不自动写入。
2. 先展示完整预览，运营点击一次批量标注。
3. 二次确认后按小批次提交。
4. 提交后重新读取 `isAssessed` 进行回读校验。
5. 网络或权限异常时停止，不静默重试写入。

真实接入时使用领星页面已有会话，不把 `auth-token` 写入日志、文件或第三方服务。
