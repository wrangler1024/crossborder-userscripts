# 型号助手采集共存候选

版本：0.1.23；分支：codex/variant-miaoshou-coexistence；基线：6dda26ce88954af6dd8576d3dc7797b127d45ce5。

## 变更

第三方采集器程序化换颜色时，型号助手可能在旧数据与新 URL 不一致的间隙排队刷新。候选版识别妙手 `earth-wxt-loading-mask` 内的 `earth-wxt-loading-spinner`，在忙碌期间取消已排队副作用、撤下界面、放行快捷键，阻止重新挂载和规格记忆。信号检查也放在刷新和点规格的执行边界，覆盖观察器尚未回调的窗口。

该信号是忙碌遮罩，不是采集独占协议：其他使用同一遮罩的操作也短暂避让。待机底栏/侧栏不触发避让；未知结构默认正常，由手动暂停兜底。不访问第三方存储或业务消息桥，不增加权限。

遮罩退场后，URL/规格稳定至少 800ms 再按当前页面恢复；清除旧的刷新/规格记忆。若数据仍不一致，暂不自动刷新，继续阻止不安全复制；一致样本或后续人工规格点击恢复原自动刷新策略，人工“重新解析”也可重新校验。精简链接 `skucode` 定位保持可用。

手动暂停通过面板 ⏸ 开启，当前标签页 sessionStorage 保存；刷新后仍暂停。暂停态只有可拖动的恢复按钮，不运行自动选型或拦截快捷键；点击后恢复。浏览器禁用 sessionStorage 时仅保证当前文档内暂停。
